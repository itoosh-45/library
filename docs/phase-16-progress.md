# שלב 16 — Excel מלא ומיפוי קובץ פשוט

3 באוקטובר 2026. App 0.14.0, schema 2, JSON 8, Excel template 1. שלב 16 נבנה מקומית. אין פרסום מוצר או שינוי GitHub Pages; ספר הפרויקט נשמר ללא שינוי.

## מה נבנה

כלי Excel בהגדרות, בטעינה עצלה, עם ספריית XLSX אחת: SheetJS CE 0.20.3 מהמקור הרשמי ורישיון Apache-2.0. קובץ מלא עם כל 17 הגיליונות שנדרשו, קשרים מסודרים, מקורות מידע, הגדרות וכל היסטוריית ההשאלות. Manifest כולל סוגי עמודות והסברי עריכה. קובץ Books פשוט עם הצעות מיפוי עברית/אנגלית וכמות עותקים המתרחבת לרשומות נפרדות. מידע ספר חסר נשאר null; מועד יצירה חסר נרשם כמועד הייבוא הראשון. ISBN/דאנאקוד מספריים נדחים כדי שלא להמציא אפסים.

preview אינו כותב. קובץ מלא מאפשר מיזוג או החלפה, וקובץ פשוט מיזוג בלבד. משתמשים באותם שירותי אימות וכתיבה אטומית שנבדקו בשלב 15. תמיד נדרשים גיבוי JSON מגן, אישור סקירה ואישור שמירה; בסתירות/ספרים דומים נדרשת הכרעה מפורשת. שינויים בזמן הסקירה אינם נדרסים. ייבוא חוזר של אותו קובץ פשוט מזהה את המזהים והמועד המקוריים.

ImageRefs אינו מכיל תמונות. משתמשים ב־Blob קיים תואם id/hash ביעד, ואחרת מסירים את הקשר בקלט ומציגים אזהרה וספירה. אין fetch. טיוטות צילום מדף אינן ב־Excel; החלפה מזהירה על הסרתן, ומיזוג שומר את טיוטות היעד. JSON נשאר גיבוי מלא. יצוא Excel אינו מקודד תמונות ל־base64 כדי לא להעמיס שלא לצורך.

שגיאות תא וקשרים מזוהות עם גיליון/שורה/עמודה, כולל שורות ריקות באמצע, מעגל וחפיפה. שגיאה כללית שאינה שייכת לתא בודד מסומנת ברמת חוברת; אין המצאת שורה. תיקוני הבדיקה לא עקפו חסימות: בבדיקת שינוי במקביל אושר במפורש לשמור ספר בעל ISBN דומה בנפרד.

## ביקורת וביצועים

נכונות: snapshot עקבי, התאמת סוגים, הקשרים וטיוטות חסרות מוסברים, אימות קלט ותוצאה לפני transaction, ואישור כפילות/סתירה. קריאות: סכמת גיליונות, ZIP, קובץ פשוט ומסך נפרדים, ללא API כללי נוסף. ארכיטקטורה: reuse של validator/merge/restore, בלי schema חדש, worker ללא מדידה או dependency שנייה ל־XLSX. אבטחה: whitelist בשני הכיוונים, דחיית formula/macro/external links, גבולות ZIP מנופח בפועל, React מציג טקסט, ללא סודות/רשת בייבוא. ביצועים: טעינה עצלה; תמונות אינן מקודדות ביצוא טבלאי; גבולות קלט מפורשים, בלי טענת ביצועים של קובץ גדול ב־iPhone.

build: ליבת index ‏134.76KB gzip, runtime ‏9.13, CSS ‏3.62 ו־HTML ‏0.43 — כ־147.94KB יחד. חבילת Excel כ־169KB gzip, מחוץ לטעינת הליבה. Vite מזהיר על chunk מעל 500KB לפני gzip; לא שונה סף האזהרה. PWA שומרת assets לצורך אופליין; טעינה עצלה מתייחסת לטעינת/הרצת הכלי באפליקציה, ולא להבטחה שה־service worker אינו מוריד אותו בזמן התקנה.

ניסוי ביקורת יחיד, בעותק פרטי: הסרת מגבלת הניפוח בפועל גרמה לבדיקת ה־ZIP המזויף להיכשל; החזרת הקוד העבירה אותה. מקור השרת האישי לא שונה. אין ניסויי ספריות חלופיות או benchmark חוזר; הרצות חוזרות נדרשו רק בעקבות כשלים/שינוי. פלטי ביקורת פרטיים אינם ב־Git.
