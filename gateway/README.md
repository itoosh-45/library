# שירות הקטלוג — מקומי

השירות מיועד להשלמת חוזה הקטלוג בספר הפרויקט. כעת הוא פועל ב־loopback בלבד; אין פריסה ל־Oracle, hostname ציבורי, חיבור ל־n8n או מסד שרת. GET `/health` מוכיח שירות, לא חיבור ספק.

```sh
npm run build:gateway
npm run start:gateway
```

השירות נפתח ב־http://127.0.0.1:4333/health . POST `/catalog/search` מקבל רק `{provider, query}`, עם ששת שדות החיפוש הקיימים. Origin מוגבל ל־127.0.0.1:4330/4331, Host חייב להתאים לכתובת המקומית, ואין cookies או URL לקוח. מגבלות: גוף 4KB, תשובת ספק 2MB, timeout של 12 שניות, שתי פניות פעילות, בקשה לכל ספק אחת ב־10 שניות ותקרה יומית מפורשת. Retry-After עובר ללקוח, ללא סבב מפתחות או ספק חלופי.

NLI/Google כבויים ללא תצורת מפתח ומכסה מאושרת. הסודות הם משתני סביבה של תהליך השרת בלבד, מחוץ ל־Git; אין להקליד אותם בצ׳אט או לשים אותם ב־VITE_*:

- `GOOGLE_BOOKS_API_KEY`, `GOOGLE_BOOKS_DAILY_LIMIT` — Google Books.
- `NLI_API_KEY`, `NLI_DAILY_LIMIT`, `NLI_MAPPING_VERIFIED=true` — מתאם ומיפוי בקוד נבדקו ב־fixtures; דגל האימות אינו נקבע עד אימות מועמד חי ומכסה. ברירת המחדל משאירה אותו כבוי.

המיפוי משתמש רק בשדות ספר מותרים. ב־NLI נצפה JSON-LD עם שדות URI ומערכי `@value`. סוג חומר לא מוכר נשאר רמז כללי עם שם ויוצר בלבד; אין העתקת שנת מהדורה/ISBN ממנו. `material_type=books` נדחה בניסוי החי ולכן אינו נשלח במתאם. `Errors` בבקשה עתידית מפסיק חיפוש כדי לא להציג תנאים שהתעלמו מהם. חיפוש NLI לפי ISBN/דאנאקוד אינו מאומת ונשאר מסלול ידני; אין תרומת מתרגם אוטומטית למחברים.

זהו שירות פיתוח; אין לפרסם אותו כפי שהוא. פריסה כוללת הגנת ניצול ציבורית, מכסה עמידה בפני restart, TLS, בידוד יציאה ותהליך, בדיקות T07/T24/T26 ו־rollback עצמאי. CORS אינו אימות ואין מכסה אמיתית של ספק שנגזרת ממספרי מגבלות מקומיים.
