# שלב 5 — ארגון הספרייה

המשך התוכנית שאושרה: מדפים, תגיות, ז׳אנרים וסדרות במאגר הקבוע בלבד. אין פרסום מוצר, שינוי Pages, שירות חיצוני או נתוני משתמש בבדיקות.

## מימוש

1. הרחבת גיבוי בסיסי לגרסה 2 ולסכמת מסד 2 לפני כתיבת הישויות החדשות. כולל מדפים, קשרי ספר־מדף, ז׳אנרים, תגיות וסדרות עם מצב קיפול. אימות שמות, קשרים, תמונות, ספירות, מספרי סדרה ומעגלים. גרסה 1 משלב 4 מתקבלת עם אוספים ריקים. preview, גיבוי מגן, אישור מפורש, fingerprint ושחזור אטומי נשמרים. ישויות עתידיות לא נתמכות ממשיכות לחסום גיבוי במפורש.
2. שירותי מדפים בעסקאות: יצירה/עריכה עם שם ותמונה, שינוי הורה, דחיית מעגלים והורים חסרים. מחיקת מדף מסירה את שיוכיו ומעבירה את ילדיו להורה שלו; ספרים ועותקים נשמרים. חישוב העץ והצאצאים איטרטיבי, כולל עומק 100. הספירות הן ספרים ייחודיים בתצוגה הנבחרת, עם אפשרות לכלול ארכיון.
3. בחירת כמה מדפים/ז׳אנרים/תגיות בכרטיס הספר, ז׳אנרים מוכנים לבחירה ויצירה עצמית. מסך ארגון תגיות/ז׳אנרים/סדרות עם שינוי שם ומחיקה שמסירה שיוך בלבד. הרשימות המוכנות אינן יוצרות ספרים או נתונים אוטומטית.
4. קיבוץ סדרות ברשימות: מיקום הקבוצה לפי ספרה הראשון במיון שם הקיים; בפנים מספר בסדר מספרי, מספר חסר בסוף ומסומן ״ללא מספר בסדרה״, שוויון לפי שם ומזהה. קיפול נשמר במסד לכל סדרה. מספר לא שלילי, עד מיליון, כולל שבר עשרוני; מספר ללא סדרה נדחה.
5. ממשק עברי/RTL לפי העיצוב הקיים, דיאלוגים עם מקלדת, תצוגת מחשב ו־360px. עריכה ישנה של ספר או מדף נחסמת; מחיקת סיווג מעדכנת revision של ספרים מושפעים.

## בדיקות וגבולות

T11: מעגל עצמי/צאצא, שינוי הורה ומרוץ חלונות, מחיקת מדף בלי אובדן ספרים, ספר בשלושה מדפים, ספירות צאצאים ייחודיות ועומק 1/10/100.

T12: סדר 1/2/10 ומספר חסר, קיפול ורענון, עריכה ושיוכים. הרחבת T19: round trip של כל הישויות ותמונות מדף, שחזור גרסה 1, דחיית קשרים/מעגלים/שדות זרים, rollback באמצע כתיבת הישויות החדשות ושינוי מקביל.

הרצת npm run check וכל בדיקות Chrome בהקשרים מבודדים. בדיקות המכשיר וההיתכנות שנדחו נשארות פתוחות; שלב 6 ושער מחזור 3 עדיין בהמשך. אין מיזוג JSON מלא בשלב זה.
