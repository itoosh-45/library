# שלב 10 — זיהוי ספר יחיד, מימוש מקומי

App 0.8.0, סכימת מסד 2, גיבוי JSON גרסה 5. מסך בעורך הספר מאפשר בחירת תמונה או צילום דרך המכשיר, תצוגה מקדימה, חיתוך באחוזים, סיבוב והכנת JPEG מקומית. שליחה דורשת מפתח בזיכרון, אימות מפורש של Free ללא חיוב, הסכמה ולחיצה נפרדת. אין בדיקת מפתח אוטומטית.

התוצאה מוגבלת לספר יחיד ולחמישה שדות עם ראיות מתוך הטקסט הנראה. כל השדות מתחילים ללא בחירה; החלה משנה טיוטה בלבד. שמירה מפורשת שומרת ספר, עותק ומקור באותה עסקה. מקור הזיהוי כולל גרסת prompt, מודל, hash תמונה, טקסט, ראיות ואי־ודאות. בחירה מקטלוג או זיהוי מחליפה את מקור השדה; שינוי ידני מתועד. התמונה אינה הופכת אוטומטית לכריכה.

גיבוי v5 שומר מקור וראיות ללא מפתח; קורא גם v1–v4. בדיקות כוללות שחזור, שינוי ידני, דחיית מקור פגום ו־rollback מלא כששמירת מקור נכשלת.

## ראיות מקומיות

- npm run check עבר: TypeScript, ESLint, 121 בדיקות Vitest, ארבע בדיקות Node ובניית האפליקציה ושירות הקטלוג.
- כל 32 בדיקות הדפדפן עברו. נוספו שלוש בדיקות canvas אמיתי ושלוש בדיקות UI לבחירה, שמירה, רענון וגיבוי, ביטול ו־429.
- JPEG סינתטי 4000×2000 נחתך לאזור כחול 2000×2000 ומסתובב ל־1024×2048. נבדקו פיקסלים, הסרת metadata וגודל עד 1.5MB. נבדקו OffscreenCanvas, חלופת HTML והשלמת הכנה כאשר מקודד אסינכרוני אינו חוזר.
- ברוחב 360px אין גלילה אופקית. בדיקות storage, export ו־console לא מצאו מפתח דמה. אין שימוש בספריית המשתמש.
- ניסוי רגישות: היפוך תנאי נעילת השליחה גרם לכישלון בדיקה; המקור הוחזר ובדיקות מלאות עברו. הפלט פרטי ומוחרג מ־Git.

כל בקשות Gemini בבדיקות מבודדות באמצעות fetch מדומה או interception בדפדפן. אין מפתח אמיתי, חיבור Gemini חי או חיוב. תוצאות סינתטיות אינן מדידת דיוק זיהוי.

## סקירה לפני מיזוג

נכונות: סכימה קשיחה, ISBN תקין בלבד להחלה, בחירה מפורשת, עסקאות אטומיות, ביטול ופלט מאוחר. קריאות: תמונה, חוזה זיהוי, session ושמירת ספר במודולים נפרדים. ארכיטקטורה: UI נטען עצל, מקור Gemini נבדל ממועמד קטלוג, אין מסד נוסף או מפתח בעלים.

אבטחה: תמונה מוגבלת ומקודדת מחדש; מפתח private בזיכרון ובכותרת בלבד, יעד HTTPS קבוע, ללא tools או grounding, cookies, referrer או cache. תגובות מוגבלות, כולל דחיית הד מפתח מקודד. טקסט ספק מוצג כטקסט React בלבד. 429 עוצר ללא retry, תשלום או איפוס באמצעות הגדרה מחדש. מחיקת המפתח זמינה גם לאחר עצירת מכסה.

ביצועים: תמונה עד 60MP לפני הכנה ועד 2048 פיקסלים בצלע ארוכה, JPEG עד 1.5MB, תגובה עד 128KB, בקשה יחידה ו־timeout. fallback סינכרוני מוגבל לתמונה שכבר הוקטנה. מדידות מכשיר וביצועים רחבות נותרו לשלב 14. אין תלות חדשה.

## בדיקות פתוחות

המשתמש דיווח שאימת Free וללא חיוב פעיל בחשבונו; זהו דיווח משתמש בלבד, ללא מפתח אצל הסוכן או שינוי חיוב. זיהוי חי ו־benchmark של 30 תמונות עבריות, HEIC וצילום ב־iPhone: NOT RUN. בדיקת מחיקת מפתח לאחר עצירת מכסה נוספה; npm run check ושלוש בדיקות UI עברו שוב אחרי התיקון. אין להסיק שמפתח Free מתמחור הספק או לקבל מפתח בצ׳אט. שער 5 אינו מושלם בלי הראיות האלה. לפי DECISIONS.md אפשר למזג את המימוש שנבדק ולהמשיך עצמאית לשלב 11; נעילת התשלומים גוברת על כל תוכנית.
