# הספרייה שלי — שלב 4 מקומי

אפליקציה בעברית וב־RTL עם הוספה ועריכה של ספרים, מחברים ועותקים, ארכוב, תמונות כריכה ותצוגה מצומצמת/מורחבת. הנתונים נשמרים במחשב, עם גיבוי JSON ושחזור בסיסי מאומת. חיבורי קטלוג, Gemini ו־OCR עדיין בהמשך התוכנית; האפליקציה המלאה עדיין אינה שלמה.

## הפעלה במחשב

דרוש Node.js 24. הגרסאות נעולות ב־package-lock.json.

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev
```

פותחים http://127.0.0.1:4330/library/ . השרת מקומי למחשב בלבד. שם הספרייה נשמר בהגדרות ונשאר אחרי רענון. אין יצירת ספרים אישיים או נתוני דוגמה אוטומטית. המסד ייחודי לאפליקציה בשם itoosh-45.library.personal.v1; מעבר לכתובת או לדפדפן אחר יוצר הקשר אחסון אחר.

## בדיקות

```sh
npm run check
```

כולל TypeScript (גם לקוד הבדיקות), ESLint, 21 בדיקות שמירה ושחזור ו־build. בדיקות Vitest משתמשות ב־fake-indexeddb ומסדי בדיקה נפרדים; אין לראות בהן בלבד הוכחת שמירה בדפדפן.

```sh
npx playwright install chromium
npm run test:browser
```

שבע בדיקות הדפדפן משתמשות בהקשר מבודד ומאמתות IndexedDB אמיתי, שמירה אחרי רענון, rollback, שני חלונות, ניווט, רוחב 360px, CRUD עותקים, כשל אחסון, ISBN כפול, תמונה ושחזור. על מחשב עם Chrome מותקן אפשר להריץ בלי הורדת דפדפן נוסף באמצעות משתנה הסביבה PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH המצביע לקובץ ההפעלה. הבדיקות אינן מוסיפות ספרים להקשר הדפדפן הרגיל של המשתמש.

```sh
npm run preview
```

תצוגת ה־build ב־http://127.0.0.1:4331/library/ . origin זה נפרד משרת הפיתוח ולכן נתוניו נפרדים.

## מצב התוכנית

המשתמש אישר להתקדם לבנייה ולדחות את בדיקות ההיתכנות שנותרו. הן נשארות פתוחות ושער 1 אינו מסומן PASS. האפליקציה עצמה עדיין לא פורסמה. [תוכנית שלב 4](docs/phase-04-plan.md), [תוצאות הבדיקה](docs/phase-04-acceptance.md). השלב הבא: מדפים, תגיות, ז׳אנרים וסדרות.

## שימוש וגיבוי

לחץ ״הוספת ספר״ או על ספר קיים לפתיחת הכרטיס. כל השדות הם רשות. לכל ספר יש עותק ראשון; בכרטיס אפשר להוסיף ולערוך עותקים, לארכב ולהחזיר מארכיון. סמן ״כולל ספרים בארכיון״ כדי לראות ספר שכל עותקיו מאורכבים. שינוי ISBN לספר קיים מציג בחירה מפורשת ולא מאחד ספרים אוטומטית.

תמונת JPEG/PNG/WebP נשמרת כ־JPEG עד 1200px ועד 1MB. HEIC תלוי בתמיכת הדפדפן; מוצעת המרה ל־JPEG/PNG במקרה של כשל. שום תמונה אינה נשלחת לשירות חיצוני.

בהגדרות אפשר להוריד גיבוי ולבחור קובץ לשחזור. תצוגה מקדימה אינה משנה נתונים. החלפה או מחיקה מחייבות הורדת גיבוי מגן ואישור שהוא נשמר במחשב. הדפדפן אינו יכול להוכיח שהקובץ נשמר, ולכן נדרש האישור שלך. שינוי בספרייה לאחר יצירת הגיבוי המגן חוסם את הפעולה ומחייב גיבוי חדש.

הפורמט הבסיסי כולל ספרים, עותקים, מחברים, תמונות והגדרות מותרות, עד 100MB. אין בו מיזוג או ישויות השלבים הבאים. אם קיימות ישויות כאלה, הוא נחסם במפורש למניעת אובדן; הרחבתו נדרשת עם הוספתן. מפתחות API, מטמון ותוצאות זיהוי זמניות אינם נכללים. לפני ניקוי הדפדפן יש להוריד גיבוי ולוודא שהקובץ נשמר.

המאגר הקבוע לפיתוח הוא https://github.com/itoosh-45/library , בענף main. לפי בקשת המשתמש, קובצי ניסוי המצלמה הוחלפו בקובצי האפליקציה. ניסוי המצלמה נשמר בהיסטוריה ובענף camera-demo-archive, שממנו GitHub Pages ממשיך להגיש אותו. אין כאן היסטוריית היתכנות פרטית או תמונות וספרים אישיים. CI ב־.github/workflows/check.yml בודק את הפרויקט, ללא פרסום; תוצאות הריצה מופיעות ב־GitHub Actions.

## רישיונות ותשתית

React/Vite/ESLint/Vitest/Playwright ברישיונות MIT/Apache-2.0 כפי שמופיע ב־docs/package-selection.json וב־lockfile; Dexie ו־TypeScript ברישיון Apache-2.0. Heebo מוגש מקומית עם רישיון SIL OFL המצורף ב־public/fonts/Heebo-OFL.txt.

מקורות התשתית: [React](https://react.dev/learn/build-a-react-app-from-scratch), [Vite](https://vite.dev/guide/), [Dexie](https://dexie.org/docs/Tutorial/React), [Vitest](https://vitest.dev/guide/).
