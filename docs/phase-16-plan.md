# שלב 16 — Excel מלא ותבנית ספרים

מקור: WORK_PLAN.md סעיף 7.4, שלב 16 ו־T22. ממשיכים עצמאית לפי אישור המשתמש; אין תשלום או סוכן נוסף. ניסויי השוואה מצומצמים בחצי, ללא חזרה על מדידות שעברו.

מנגנון חדש מוגדר לפי הספר: SheetJS CE 0.20.3 ממקור ההפצה הרשמי, רישיון Apache-2.0, dependency נעול וטעינה עצלה. אין שימוש בגרסת npm הישנה 0.18.5. זוהי ספריית ה־XLSX היחידה באפליקציה. הוראות authoring של מיומנות הגיליונות מיועדות למסמכים נפרדים; הקבצים כאן נוצרים באמצעות מנגנון המוצר שהספר מחייב, כדי לבדוק את אותו מסלול שיפעיל המשתמש.

הקובץ המלא כולל Manifest, Books, Copies, Authors, BookAuthors, Shelves, BookShelves, Series, Genres, Tags, BookGenres, BookTags, People, Loans, MetadataSources, Settings, ImageRefs. שדות scalar בעמודות, קשרי מערכים בגיליונות הקשרים; תוכן metadata מובנה בעמודות JSON מפורשות לפי schema. Manifest מתעד templateVersion, libraryId, תאריך, כל עמודה/סוג ושדות שלא משנים. IDs/ISBN/דאנאקוד ותאריכים כתובים כטקסט; מספרים ובוליאנים לפי סוג. טקסט דמוי נוסחה הוא string. אין נוסחאות, מאקרו או קישורים חיצוניים פעילים ביצוא.

לפני הפענוח: תקרת קובץ 10MiB, ZIP לא מוצפן/ZIP64, עד 512 entries, כל entry עד 16MiB ותכולה מנופחת עד 64MiB. מוודאים התאמת local/central directory, CRC ונפח מנופח בפועל בזרם מוגבל. מסרבים DTD/entities, formula, macros ו־external relationships. מגבילים 20,000 שורות/גיליון, 64 עמודות ו־500,000 תאים לפני/אחרי parser. אין ביצוע תוכן הקובץ.

ImageRefs מכיל מזהה, hash וכתובת מקור בלבד. ייבוא משתמש בתמונה קיימת תואמת ביעד; אם אינה קיימת, מסיר את הקשר לתמונה ומציג ספירה/אישור אובדן התמונות. אין fetch. טיוטות vision אינן ב־Excel; לפני החלפה מוצגת אזהרה על כך. JSON נשאר הגיבוי המלא. ייבוא מלא משתמש באימות הגיבוי הקיים ובמסלולי החלפה/מיזוג האטומיים, עם גיבוי JSON מגן. דוח בעיות לפי גיליון/שורה/עמודה, כולל קשרים ושדות לא נתמכים.

קובץ פשוט: גיליון Books בלבד (או גיליון יחיד ללא Manifest), כותרות בעברית/אנגלית, מיפוי מפורש. מחברים מופרדים ב־`;`, כמות עותקים מתרחבת לרשומות; נתונים חסרים נשארים null. נוסחאות נדחות גם אם יש להן cached value. תאריך/מטבע/הערות עותק נתמכים. המזהים נגזרים מטביעת הקובץ/גיליון/שורה כדי למנוע כפילות בייבוא חוזר של אותו קובץ. מיזוג בלבד לקובץ פשוט; בחירה מפורשת לספרים דומים, לא איחוד מהדורות.

בדיקות נדרשות מרוכזות ב־T22: round trip כל הטבלאות, עברית/גרש/אפסים/נוסחה כטקסט, עותקים/תאריכים/מטבע, formula cached/error, unknown sheets/columns, IDs וקשרים, ZIP מנופח/מזויף, atomic import ושינוי בזמן preview. template מלא סינתטי ו־Books פשוט יהיו artifacts של המוצר. פתיחה בכלי Excel בפועל וב־iPhone תישאר NOT RUN בלי בדיקת המשתמש; העבודה תמשיך בלי תשובה.
