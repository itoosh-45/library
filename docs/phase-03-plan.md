# שלב 3 — אפליקציה וליבה מקומית

## החלטת מעבר

המשתמש אישר במפורש להתקדם לבנייה המקומית ולדחות את בדיקות ההיתכנות שנותרו, בלי לסמן אותן כהצלחות ובלי לפרסם את המוצר. אישור זה משנה את תנאי הכניסה לשלב 3 בלבד. WORK_PLAN המקורי נשמר ללא שינוי; שער 1 אינו מסומן PASS. ניסוי המצלמה הציבורי נשאר כפי שהוא.

נותרו: אמת מהדורה במדגם הספרים; חיבור ומיפוי מורשים של NLI/Google Books; יתר בדיקות מכשיר וזיהוי מדף; חלון עומס שרת מייצג. קבלת מודל הגיבוי והוויתור על בדיקתו אינם נפתחים מחדש. אין הקמת gateway או שינוי n8n בשלב זה.

## הבנייה

- תיקיית מוצר נקייה outputs/library-app עם היסטוריה עצמאית; אין העתקת נתוני ספרים, תמונות, מפתחות או היסטוריית ההיתכנות. remote מיועד: https://github.com/itoosh-45/library, ללא push או deploy בשלב זה.
- React ו־TypeScript באמצעות Vite, גרסאות תואמות ונעולות ו־lockfile. ESLint ו־Vitest; בדיקות דפדפן אמיתי בנפרד. GitHub Actions לבדיקות בלבד, ללא פרסום.
- עברית ו־RTL, גופן מקומי, פלטת ״קטלוג חד״ המאושרת, ניווט פנימי ב־hash ומצבי טעינה/שגיאה/ספרייה ריקה. אין יצירת דוגמאות אישיות אוטומטית.
- Dexie schema v1 לפי ישויות הספר בפרק 4: ספרים, עותקים, מחברים, מדפים, שיוכים, סדרות, ז׳אנרים, תגיות, אנשים, השאלות, תמונות, הגדרות, מקורות, cache וטיוטות זיהוי. מזהה ספרייה קבוע ושם מסד ייחודי לאפליקציה; אין מפתחות API בהגדרות.
- אתחול אטומי ושירות כתיבה שמוודא קשרי ספר/מחבר/עותק ומבטל כתיבה חלקית. אין מחיקה אוטומטית של מסד כשפתיחה נכשלת.
- README להפעלה ופקודות install/typecheck/lint/test/build. עריכת הספרים וזרימות OCR/קטלוג המלאות נכנסות בשלבים הבאים.

## בדיקת סיום — T08 וחלקי T01/T25/T30

1. פתיחת מסד חדש יוצרת את כל הטבלאות וזהות אחת; פתיחה חוזרת שומרת אותה.
2. כתיבה תקינה שומרת ספר ועותק באותה עסקה; קשר חסר או כשל באמצע מבטלים את כל הכתיבה.
3. מסד נסגר ונפתח מחדש ללא איבוד הנתונים. בדיקת דפדפן אמיתי מאמתת IndexedDB ולא מסתמכת רק על fake-indexeddb.
4. בדיקות התקנה מה־lockfile, typecheck, lint, Vitest ו־build עוברות.
5. המסך בעברית וב־RTL, ניווט ורענון hash פועלים, 360px ללא overflow, שגיאת אחסון מוצגת ולא מוחקת ספרייה. בדיקה במחשב אינה בדיקת iPhone.
6. אין מפתחות, נתוני אמת או שדות שנשללו בקוד/תוצר הבנייה. אין בקשות לספקים או פרסום. תוצאות השלב מתועדות בנפרד מהבדיקות שנדחו.

מקורות לבחירת התשתית: [React](https://react.dev/learn/build-a-react-app-from-scratch), [Vite](https://vite.dev/guide/), [Dexie](https://dexie.org/docs/Tutorial/React), [Vitest](https://vitest.dev/guide/). גרסאות ורישיונות נבדקים גם מול npm בזמן ההתקנה.


## תוצאת סיום

שלב 3 המקומי עבר לפי החרגת המעבר שאושרה: התקנה מה־lockfile, TypeScript, ESLint, 8 בדיקות שמירה, 3 תרחישי Chrome ו־8 בדיקות build-preview. תצוגות מחשב ו־360px נסקרו. מסד אמיתי יוצר 15 טבלאות ושומר זהות ונתונים אחרי רענון; כשל מבטל עסקה. אין בדיקת iPhone פיזית או GitHub Actions חי. אין פרסום. הבדיקות שנדחו נשארות פתוחות; הן אינן חוסמות את הבנייה המקומית שהמשתמש אישר. הבא: שלב 4, ספרים/עותקים/גיבוי בטיחות בסיסי.
