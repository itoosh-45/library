# סידור מידע ופרטי ספר — 0.23.0

המשתמש אישר ב־7 באוקטובר 2026 את סדר הלשוניות מימין לשמאל: מדפים, כל הספרים, השאלות, תגיות. ברירת המחדל נשארת כל הספרים. תמונות Handy Library הן ייחוס למבנה מידע בלבד; הצבעים, Heebo והזהות הקיימת נשמרים. מדפים מוצגים ברשימה עם תמונה מימין, שם וספירה. רשת כריכות הספרים נשמרה משום שלא נבחרה חלופה לשאלת הרשימה/הרשת. עריכת הספר נפתחת בלחיצה כפי שכבר פעלה; לא נוספה תצוגה נפרדת ללא אישור.

טופס הספר מציג שם, סדרה ומספר, מהדורה, ז׳אנר, מחברים מפוצלים, כריכה, הוצאה, תאריך פרסום וסוג כריכה. מספר מחברים נתמך. תאריך מלא נשמר רק כאשר ידוע; שנה או חודש בלבד מקטלוג אינם משלימים יום מומצא. שמות קיימים שלא פוצלו נשמרים ללא ניחוש; עריכת כותרת בלבד אינה משנה את המחברים. מחיר נשאר בפרטים נוספים. הערות ישנות נשמרות בנתונים ובגיבוי, אך שדה הערות ותקציר אינם מוצגים לפי בקשת המשתמש. לא נוספו FAQ, עזרה, אודות, שדרוג או Skoolib.

תגיות הן לשונית עם ספירת ספרים, בחירת תגית וניהול; אפשר לשייך אותן בטופס הספר. הגדרות מוצגות כשורות מרווחות של הכלים הקיימים. ניהול התגיות עבר ללשונית המיועדת.

## תאימות נתונים

תאריך פרסום וסוג כריכה הם שדות אופציונליים ללא שינוי אינדקסים או מחיקת נתונים. JSON מלא עולה לגרסה 11 כאשר השדות מופיעים בספרים או במקורות מידע, ועדיין קורא גרסאות 8–10 והעטיפות הישנות. Excel מלא עולה ל־template 3 וממשיך לקרוא 1–2. שדות פיצול המחבר כבר קיימים בסכימת Authors. גיבוי JSON ו־Excel שומרים אותם. Excel פשוט תומך גם במיפוי תאריך פרסום וסוג כריכה.

## מחקר Goodreads — טרם חובר לאפליקציה

המחקר נענה לבקשת המשתמש לחיפוש מידע על ספר, ללא ספרייה או חשבון Goodreads וללא ייבוא CSV.

- [קבוצת המפתחים הרשמית](https://www.goodreads.com/group/show/8095-goodreads-developers): אין מפתחות API חדשים מאז דצמבר 2020.
- [מדריך Scrapfly שסופק](https://scrapfly.io/blog/posts/how-to-scrape-goodreads): JSON-LD ו־Apollo בתוך `__NEXT_DATA__`, עם מיפוי מהדורה. קריאת המדריך אינה שימוש בשירות שלהם.
- [מדריך Apify שסופק](https://blog.apify.com/goodreads-data-without-api/): Actor חיצוני שמקבל מילות חיפוש או URL. נדרש חשבון ו־token לשימוש בתוכנה; אין שימוש בו במסגרת המחקר.
- [תנאי Goodreads](https://www.goodreads.com/about/terms?id=188), סעיף 1: רישיון האתר אינו כולל כלי איסוף אוטומטי. זו מגבלת המקור לצד ההיתכנות הטכנית.

בדיקה רגילה מ־Node, ללא שינוי User-Agent, מפתח, התחברות, שירות scraping או עקיפת אימות, החזירה HTTP 200 לדף ציבורי באנגלית ולמהדורה העברית [מרטאג](https://www.goodreads.com/book/show/247411944). JSON-LD מכיל שם, כריכה, מחברים, פורמט, עמודים ושפה; Apollo מכיל גם פרטי מהדורה, ISBN, הוצאה, זמן פרסום וקשר לסדרה. חיפוש יחיד לפי ״מרטאג״ החזיר 200 וקישור למהדורה העברית. תוכן מלא, ביקורות ותמונות לא נשמרו במאגר.

לדף הספר אין `Access-Control-Allow-Origin`, ולכן `fetch` ישיר מהאפליקציה בדפדפן אינו פתרון. המסלול האפשרי הוא חיבור דרך שרת הקטלוג הקיים: חיפוש מוגבל, קריאת מהדורה שנבחרה, אימות שדות וכריכה, הצעת מילוי לפני שמירה ומטמון. תגובת אימות, חסימה או שינוי מבנה צריכים להפסיק את הקריאה עם הודעה, ללא ניסיון עקיפה או מעבר לשירות בתשלום. הצלחה בשתי מהדורות אינה בדיקת יציבות או כיסוי בכל הספרים.

אין חיבור Goodreads פעיל, פריסה של שרת או חשבון Scrapfly/Apify. אין תשלום, חיוב, הרשמה או שינוי ב־n8n. שילוב מקור נוסף באפליקציה הוא שלב נפרד מהמחקר ומהתאמות הממשק שכבר אושרו.

## בדיקה וסקירה

בדיקות שמירה מכסות תאריך לוח שנה תקין ושנה תואמת, JSON ו־Excel עם שם מפוצל, שמירת שדות מעריכה במסך ישן ודחיית שם מפוצל סותר. בדיקות דפדפן מכסות ניווט, תגיות, עריכת פרטי ספר, סריקה וגיבוי. בדיקות טלפון הן הדמיות Chrome ו־WebKit, ולא בדיקת מכשיר פיזי.

הגלאי המכני של impeccable סימן תמונת כריכה עם src שמוגדר בזמן ריצה, וקווי הדגשה ב־CSS הישן. טעינת הכריכה נבדקת בדפדפן; ה־CSS הישן נשמר במסגרת בקשת שמירת העיצוב. לא נוספו קווי ההדגשה שסומנו.

תוצאות סופיות: `npm run check` עבר (208 בדיקות יחידה ו־4 בדיקות Node, טיפוסים, lint ושתי הבניות); 21 בדיקות Chrome עברו; 7 בדיקות WebKit עברו. אין בדיקת מכשיר פיזי. סקירת correctness/readability/architecture/security/performance בוצעה ללא סוכנים נוספים; אין ספק חדש פעיל, מפתחות, נתוני משתמש או תמונות במאגר.

8 בדיקות PWA עברו, כולל בדיקת XSS ממוקדת לאחר התאמתה לשדה סוג הכריכה, גיבוי ושחזור JSON 11 עם המחבר המפוצל, אופליין ועדכון בטוח. ניסוי mutation הפך זמנית את תנאי אימות התאריך: שתי בדיקות נכשלו כמצופה; הקוד המקורי הוחזר ושלוש הבדיקות עברו.

## סקירה אחרונה לפני המשך — 7 באוקטובר 2026

לפי בקשת המשתמש בוצעה סקירה חוזרת של איפוס אטומי, טיפול בשגיאות סריקה, אישור חיפוש אחרי OCR, שמירת פרטי ספר ותאימות גיבויים. לא נמצא תיקון נדרש נוסף בקוד המוצר. `npm run check` עבר שוב עם 208 בדיקות יחידה ו־4 בדיקות Node. כל 7 בדיקות WebKit וכל 8 בדיקות PWA עברו בריצות מלאות.

בריצת Chrome הראשונית בדיקת עריכת פרטי הזיהוי לא קיבלה את תוצאת ההדמיה: החלפת פונקציה פנימית בייבוא מודול אינה גבול בדיקה יציב בשרת פיתוח עם עדכוני מודולים. הבדיקה שונתה להדמיית תגובת Gemini דרך Playwright, לפי דפוס הבדיקות הקיים, ולכן בודקת גם את מסלול תגובת הספק והייחוס למקור. לא בוצעה קריאה אמיתית לספק. ניסוי mutation ביטל זמנית את החיפוש בכפתור האישור; הבדיקה נכשלה משום שלא נשלחה שאילתת חיפוש, כמצופה. הקוד המקורי שוחזר וכל 21 בדיקות Chrome עברו בריצה מלאה. טיפוסים ו־lint עברו גם לאחר תיקון הבדיקה.

השינויים בממשק ובסריקה כבר מוזגו ב־PR #1; תיקון הבדיקה והתיעוד הם המשך קטן. אין פרסום לאתר, שינוי בשרת Oracle או חיבור Goodreads במסגרת הסקירה. בדיקות מכשירים פיזיים ודיוק OCR בתמונות המשתמש עדיין אינן מאומתות.
