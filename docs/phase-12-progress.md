# שלב 12 — סקירת מדף ושמירת מאושרים, מימוש מקומי

App 0.10.0, סכימת מסד 2, גיבוי v7. אותה רשימה נגללת מציגה crop מקומי מתוך bbox או מקור מלא כשהמיקום חסר, טקסט, אי־ודאות, הצעות חפיפה ועורך פרטני. שדות מהתמונה מתחילים ללא בחירה. ערכים, בחירות קטלוג והחלטה נשמרים בטיוטה; אישור וסיכום לפני שמירה הן פעולות נפרדות.

לכל פריט נשמרים itemId קבוע ומצב זוהה/נבדק/אושר/נשמר/הוסר. עדכון ערכים מחזיר מצב לנבדק. החלטת ספר חדש או עותק נוסף מפורשת; ISBN שכבר קיים דורש בחירת עותק או אישור ספר נפרד. בהוספת עותק פרטי הספר הקיים נשמרים, מקור הצילום מתועד כראיות בלבד, ושיוך המדף נוסף. חפיפה אינה איחוד אוטומטי.

״שמור מאושרים״ מציג מספר ספרים חדשים, עותקים נוספים ופריטים שלא יישמרו ורשימה פרטנית. נדרש אישור הסיכום. הכתיבה לספרים, עותקים, מחברים, מדפים ומקורות יחד עם סימון פריטי הטיוטה היא transaction אחת. revision, רשימת הפריטים וסיכום נבדקים מחדש; שינוי חלון או יעד עותק מבטל סיכום ישן. חזרה על אותה שמירה מחזירה אפס כתיבות, גם בשני חלונות.

מקור shelf-v1 כולל batchId/itemId ו־hash/ראיות מהצילום; שינוי ידני נשאר נבדל מהמקור. מקור single-book-v1 קיים נשאר נתמך. במקור צילום שלא הוחלו ממנו שדות, selectedFields ריק במפורש; אינו מתיימר להיות מידע שהועתק לספר. גיבוי v7 שומר החלטות, עריכות, מקורות ומצב שמור; קורא v1–v6. לאחר מחיקת ספר עם גיבוי מגן פריט הטיוטה מסומן הוסר והקישור השמור מנוקה; ראיות התמונה נשמרות.

## בדיקות

npm run check עבר: TypeScript, ESLint, 141 בדיקות Vitest, ארבע בדיקות Node ובניית הלקוח והשירות. עשר בדיקות שלב 12 כוללות 50 פריטים, אישור מפורש, עותקים ושמירה מתחרה, ISBN שקול, סיכום פגום או ישן, כשל כתיבה המחזיר את כל העסקה, עריכת מקור/קטלוג, גיבוי ושחזור וקבלת טיוטת v6 ללא אישור אוטומטי.

כל 38 בדיקות הדפדפן עברו. שלוש בדיקות חדשות משתמשות ב־IndexedDB וב־canvas אמיתיים: crop של 450×600, בחירת שדות שלא נבחרו מראש, חזרה לעריכה מהודעת ויתור, ביטול סיכום, שמירה ורענון/גיבוי; שני חלונות מתחרים מוסיפים שני עותקים פעם אחת ושומרים את ערכי הספר; רשימה של 50 נערכת בפריט 25, שדה נבחר מקטלוג נשמר ונבדק רוחב 360px. כל הנתונים סינתטיים, הקטלוג מדומה, ולא בוצעה בקשת Gemini חיה.

ניסוי רגישות החליף זמנית סינון מאושרים בסינון נבדקים. הבדיקה זיהתה כתיבה לפריט הלא מאושר; המקור הוחזר לפני הבדיקות המלאות. הפלט פרטי ומוחרג מ־Git.

כשל שנמצא ב־50 פריטים נבע מהמתנות שאינן מבצעות DB בתוך העסקה. בדיקות החלטה סינכרוניות אינן ממתינות עוד; שאילתות DB נשארות בתוך העסקה. העיקרון תואם [תיעוד Dexie על סגירת עסקה מוקדמת](https://dexie.org/docs/DexieErrors/Dexie.PrematureCommitError). הודעת ויתור ב־Sheet שומרת כעת את העורכים mounted ומסתירה אותם זמנית; ״חזרה לעריכה״ משמרת שדות מקומיים שלא נשמרו.

## סקירה

נכונות: אישור פרטני, בדיקה חוזרת לפני כתיבה, rollback ומזהים יציבים. קריאות: חוזה ערכי סקירה, שירות עסקאות ועורך UI מופרדים; נעשה שימוש בשירותי הספר והקטלוג הקיימים. ארכיטקטורה: אותו מסד וסכימה, מסך עצל, ללא ספריית צד שלישי חדשה.

אבטחה: input/candidate/evidence עוברים whitelist; אין שדות מפתח בחוזה או בגיבוי. crop נשאר מקומי. החלטת copy אינה מחילה ערכי טיוטה על הספר. נעילת תשלומים והסכמה לשליחת Gemini נשארות בתוקף. ביצועים: ערכי ספרים לחיפוש יעד נקראים רק כשעורך פריט פתוח; טופסי פריטים סגורים אינם מרנדרים שדות/קטלוג. מסך המדף כ־23.7KB לפני gzip ונטען עצל. מדידות p95 רחבות נותרו לשלב 14.
