# הספרייה שלי — שלב 8 בבנייה מקומית

אפליקציה בעברית וב־RTL עם הוספה ועריכה של ספרים, מחברים ועותקים, ארכוב, תמונות כריכה ותצוגה מצומצמת/מורחבת. מדפים לוגיים מקוננים עם תמונה, תגיות וז׳אנרים מרובים וסדרות מתקפלות עם מיון מספרי. הנתונים נשמרים במחשב, עם גיבוי JSON ושחזור בסיסי מאומת. בחירת שדות קטלוג ו־Open Library נבנו מקומית; חיבורי NLI ו־Google Books, Gemini ו־OCR עדיין דורשים השלמה; האפליקציה המלאה עדיין אינה שלמה.

## הפעלה במחשב

דרוש Node.js 24. הגרסאות נעולות ב־package-lock.json.

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev
```

פותחים http://127.0.0.1:4330/library/ . השרת מקומי למחשב בלבד. שם הספרייה נשמר בהגדרות ונשאר אחרי רענון. אין יצירת ספרים אישיים או נתוני דוגמה אוטומטית. המסד ייחודי לאפליקציה בשם itoosh-45.library.personal.v1; מעבר לכתובת או לדפדפן אחר יוצר הקשר אחסון אחר.

## בדיקות

```sh
npm run check
```

כולל TypeScript (גם לקוד הבדיקות), ESLint, 92 בדיקות שירותים, חיפוש, מיון, השאלות, קטלוגים, שמירה ושחזור, 4 בדיקות כלי החיבור המקומי ו־build. בדיקות Vitest משתמשות ב־fake-indexeddb ומסדי בדיקה נפרדים; אין לראות בהן בלבד הוכחת שמירה בדפדפן.

```sh
npx playwright install chromium
npm run test:browser
```

21 בדיקות הדפדפן משתמשות בהקשר מבודד ומאמתות IndexedDB אמיתי, שמירה אחרי רענון, rollback, שני חלונות, ניווט, רוחב 360px, CRUD עותקים, כשל אחסון, ISBN כפול, תמונה ושחזור, עץ מדפים של 100 רמות, מעגלים בשני חלונות, שיוכים מרובים, ספירות ייחודיות ומצב קיפול סדרות. נוספו שלושה עותקים לשני אנשים, שמות כפולים, מרוץ השאלה/החזרה, זמינות חיה והיסטוריה אחרי ארכוב ושחזור; בשלב 8 נוספו בחירת שדות קטלוג, עריכה ידנית ומקורות מידע בגיבוי. על מחשב עם Chrome מותקן אפשר להריץ בלי הורדת דפדפן נוסף באמצעות משתנה הסביבה PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH המצביע לקובץ ההפעלה. הבדיקות אינן מוסיפות ספרים להקשר הדפדפן הרגיל של המשתמש.

npm run preview

תצוגת ה־build ב־http://127.0.0.1:4331/library/ . origin זה נפרד משרת הפיתוח ולכן נתוניו נפרדים.

## חיפוש, סינון ומיון

החיפוש חי לפי שם, מחבר ותגיות בכל הספרייה. אפשר לצרף כמה מסננים: מדף עם/בלי צאצאים, ז׳אנר, כל התגיות שנבחרו, מצב קריאה, זמינות, הוצאה, שפה ושנה. ניקוד, טעמים, צורות Unicode, גרשיים ואותיות סופיות מנורמלים לחיפוש בלבד; הטקסט השמור נשאר מקורי.

מיון עולה או יורד לפי הוספה, שם, מחבר, שנה, ז׳אנר, עמודים ומחיר, עם ערכים חסרים בסוף. המחיר הוא הנמוך בעותקים פעילים, בקבוצות מטבע ללא המרה. סדרות נשארות מקובצות; מיקום הקבוצה לפי הספר הראשון במיון שנבחר, ובפנים מספר סדרה, שם ומזהה. פס אותיות מעל שמונה תוצאות במיוני שם/מחבר/ז׳אנר פותח סדרה וממקם את הכותרת בלי לפרק אותה. חזרה מעריכה שומרת את החיפוש, המסננים והגלילה באותו מסך; רענון מאפס את החיפוש והמסננים.

בסטטיסטיקה אפשר לבחור את תוצאות החיפוש או את הספרייה כולה, כולל ארכיון. ספרים ייחודיים, עותקים פעילים ומאורכבים נספרים בנפרד, לצד מצבי קריאה, תגיות וז׳אנרים. נתוני חיפוש ומיון אינם נשמרים במסד או בגיבוי; מצב קיפול סדרות ממשיך להישמר.

## אנשים והשאלות

בכרטיס הספר פותחים ״השאלת עותק״, בוחרים עותק זמין ואדם קיים או מזינים שם חדש. כשיש כמה עותקים נדרשת בחירה מפורשת. תאריך ההשאלה היום או בעבר; תאריך החזרה צפוי הוא רשות. שמות זהים אינם מתאחדים: מאשרים שזהו אדם נוסף והבחירה מבדילה ביניהם במספר. ברשימה מופיעים תג ״מושאל״ ומספר העותקים הזמינים, שמתעדכנים גם בחלון אחר.

בטאב ״השאלות״ רואים אנשים, השאלות פתוחות והיסטוריה. ״רישום החזרה״ רושם את היום ושומר את ההיסטוריה. ארכוב אדם/עותק בעל השאלה פתוחה חסום; אדם שהחזיר הכול ניתן לארכוב והיסטורייתו נשמרת. השאלה והחזרה חסומות בכרטיס עם שינוי ספר/עותק שלא נשמר. ״באיחור״ מופיע בתוך האפליקציה בלבד, ללא הודעות או תזכורות חיצוניות. אין מחיקה של אנשים או השאלות; ספר בעל היסטוריית השאלה נשמר גם לאחר החזרה.

## שימוש וגיבוי

לחץ ״הוספת ספר״ או על ספר קיים לפתיחת הכרטיס. כל השדות הם רשות. לכל ספר יש עותק ראשון; בכרטיס אפשר להוסיף ולערוך עותקים, לארכב ולהחזיר מארכיון. סמן ״כולל ספרים בארכיון״ כדי לראות ספר שכל עותקיו מאורכבים. שינוי ISBN לספר קיים מציג בחירה מפורשת ולא מאחד ספרים אוטומטית.

תמונת JPEG/PNG/WebP נשמרת כ־JPEG עד 1200px ועד 1MB. HEIC תלוי בתמיכת הדפדפן; מוצעת המרה ל־JPEG/PNG במקרה של כשל. שום תמונה אינה נשלחת לשירות חיצוני.

במסך המדפים אפשר ליצור ולערוך מדף עם תמונה ולהעביר אותו להורה אחר. ההורה לא יכול להיות המדף עצמו או צאצא שלו. בוחרים מדף כדי לראות ספרים ישירים או גם ספרי תתי־מדפים; כל ספר נספר פעם אחת בתצוגה, ללא קשר לכמות העותקים או השיוכים. מחיקת מדף שומרת את הספרים ומעבירה את ילדיו להורה שלו.

בכרטיס הספר בוחרים כמה מדפים, ז׳אנרים ותגיות. אפשר ליצור ז׳אנר מוכן או שם אישי, וליצור תגית וסדרה. במסך ״תגיות וסדרות״ מנהלים את שלושת סוגי האוספים. מחיקת אוסף מסירה את השיוך ושומרת את הספרים; מחיקת סדרה מסירה גם את המספרים שלה. בסדרה המספרים ממוינים מספרית (1, 2, 10); מספר חסר מופיע בסוף ומסומן. הקיפול נשמר גם אחרי רענון ובגיבוי.

בהגדרות אפשר להוריד גיבוי ולבחור קובץ לשחזור. תצוגה מקדימה אינה משנה נתונים. החלפת הספרייה או מחיקת ספר מחייבות הורדת גיבוי מגן ואישור שהוא נשמר במחשב. הדפדפן אינו יכול להוכיח שהקובץ נשמר, ולכן נדרש האישור שלך. שינוי בספרייה לאחר יצירת הגיבוי המגן חוסם את הפעולה ומחייב גיבוי חדש.

הפורמט הבסיסי בגרסה 4 כולל ספרים, עותקים, מחברים, מדפים ושיוכים, ז׳אנרים, תגיות, סדרות ומצב קיפול, אנשים והיסטוריית השאלות, מקורות מידע מהקטלוגים, תמונות והגדרות מותרות, עד 100MB. שחזור גרסאות 1–3 נתמך; גרסאות 1–2 מחליפות אנשים והשאלות ברשימות ריקות, גרסה 1 גם מחליפה אוספים, וגרסאות 1–3 מחליפות מקורות מידע ברשימה ריקה. התצוגה המקדימה מזהירה לפני החלפה. אין מיזוג JSON. מפתחות API, מטמון ותוצאות זיהוי זמניות אינם נכללים. לפני ניקוי הדפדפן יש להוריד גיבוי ולוודא שהקובץ נשמר.

המאגר הקבוע לפיתוח הוא https://github.com/itoosh-45/library , בענף main. לפי בקשת המשתמש, קובצי ניסוי המצלמה הוחלפו בקובצי האפליקציה. ניסוי המצלמה נשמר בהיסטוריה ובענף camera-demo-archive, שממנו GitHub Pages ממשיך להגיש אותו. אין כאן היסטוריית היתכנות פרטית או תמונות וספרים אישיים. CI ב־.github/workflows/check.yml בודק את הפרויקט, ללא פרסום; תוצאות הריצה מופיעות ב־GitHub Actions.
