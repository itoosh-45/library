# שלב 13 — התקנה, אופליין ועדכון, מימוש מקומי

App 0.11.0, סכימת מסד 2 וגיבוי JSON v7, הקורא v1–v7. אין שינוי מסד או dependency חדש. manifest עברי RTL, scope/start_url תחת /library/, standalone ואייקוני PNG מקוריים ב־192/512 ובטיחות maskable נוספו. הגופן המקומי ונתיבי base נבדקו ב־production.

ה־build מייצר service worker ורשימה מדויקת של shell, chunks, גופן ואייקונים. מזהה הגרסה נגזר מכל התוכן הציבורי ומתבנית ה־worker. install אטומי ברמת גרסת המטמון: כשל מוריד את המטמון החלקי ומשאיר את הגרסה הפעילה. אין מטמון runtime: POST, API, כתובות מחוץ ל־scope, query או headers עם מפתח/Authorization אינם מטופלים. נתוני ספרים, תמונות אישיות, מפתחות וקובצי גיבוי אינם נכנסים למטמון קובצי האפליקציה.

מצב רשת מוצג בטקסט. חיפוש מקוון וזיהוי נחסמים ללא רשת; בחירה, חיתוך, סריקה, עריכה, השאלה וסקירה מקומית נשארים זמינים. הגדרות מכילות הוראות התקנה, אזהרת מקור אחסון ובקשת persistence מפורשת. נתמכת תוצאה מאושרת/נדחית/לא נתמכת, תמיד עם תזכורת לגיבוי.

גרסה חדשה ממתינה לפעולה מפורשת. אין skipWaiting אוטומטי או רענון אוטומטי של חלונות קיימים. עדכון נחסם כשיש dialog פתוח, שם או מפתח בהקלדה, תצוגת שחזור או פעולת גיבוי, ועסקת כתיבה פעילה עד אירוע complete/abort של IndexedDB. לפני בקשת ההפעלה החלון נעשה inert; ה־worker מסרב כשיש חלון ספרייה נוסף. כשל/timeout מחזיר את הממשק לשימוש. רק חלון שביקש עדכון מתרענן. מטמון ישן נמחק רק כשאין גרסה ממתינה/מותקנת, יש חלון יחיד, והמודול הראשי שלו שייך לגרסה הפעילה; קבצים עצלים של חלון ישן נשמרים עד אז. פעולת הניקוי אינה נוגעת במסד הנתונים.

## בדיקות וביקורת

PASS מקומי: npm run check — טיפוסים, lint, 142 Vitest, ארבע בדיקות Node, build לקוח ו־gateway. כל 38 בדיקות הדפדפן הקיימות עברו. שש בדיקות production מבודדות ב־4334 עברו: offline reload, ספר/השאלה/החזרה, מסכים עצלים וגופן, base ו־manifest, החרגות בקשות, שתי גרסאות bundle ו־SW בזמן עריכה, שחזור ממתין/מפתח בהקלדה, שני חלונות, שימור הספרים ו־cleanup, שלושת מצבי persistence. תמונות/Gemini אמת אינם נשלחים. נתוני המשתמש ב־4331 לא שימשו בדיקות אוטומטיות.

דוחות וצילומים מקומיים נשמרים בתיקיות test-results נפרדות ומוחרגות מ־Git. צילום הגופנים/ההוראות ב־360px נוצר; גבולות שורות הטקסט ב־RTL בתוך המסך נבדקו גם דרך DOM Range. זה אינו צילום טלפון. ניסוי ביקורת הפיך הסיר את חריג query; בדיקת ההחרגות נכשלה כפי שנדרש. המקור שוחזר ולאחריו עברו הבדיקות המלאות. תוצרים פרטיים ב־private/phase13-review אינם במאגר. שרת הבדיקות שומר גרף imports עקבי לשתי הגרסאות ואינו חלק מתוצר האפליקציה.

נכונות: ללא רענון בזמן עבודה, guard לעסקה אמיתית והחרגות מוכחות. קריאות: worker, יצירת build, UI ובטיחות עדכון מופרדים. ארכיטקטורה: אותה ספרייה מקומית ו־build בלבד, ללא framework PWA חדש. אבטחה: רשימת קבצים ציבוריים סגורה, בדיקת חלון שולח וסריקת דפוסי מפתחות במקור ובתוצר ללא ממצא; אין חיוב. ביצועים: ליבה כ־134KB gzip ועוד runtime כ־9KB ו־CSS כ־3.5KB; scanner/vision/shelf chunks עצלים נשמרים מראש לאופליין. מדידות מכשיר ו־p95 נשארות לשלב 14.
