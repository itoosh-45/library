# שלב 4 — ספרים, עותקים וגיבוי בסיסי

מימוש לפי תוכנית הפרויקט המאושרת והוראת המשתמש להמשיך. הפיתוח במאגר library בלבד; הבדיקות שנדחו נשארות פתוחות. אין פרסום מוצר.

## התוצאה

כפתור הוספת ספר וכרטיס bottom sheet נגיש להוספה/עריכה. שדות רשות, כמה מחברים בלי פיצול שם, מצב קריאה ותצוגה מצומצמת/רחבה. רשימה אחת לכל ספר, ספירת עותקים, הוספה/עריכת עותק וארכוב/החזרה מארכוב. עריכה משתמשת ב־revision ומונעת דריסה מחלון ישן. ISBN נבדק ואינו גורם למיזוג שקט; התאמה מציעה לפתוח קיים, להוסיף עותק או לשמור ספר נפרד.

תמונה נבחרת מקובץ, מפוענחת בדפדפן, מצומצמת לצלע ארוכה עד 1200px ונשמרת כ־JPEG עד 1MB עם hash. אין SVG או שליחה לשירות. צילום HEIC נתמך רק אם הדפדפן מפענח; אחרת הוראה לבחור JPEG/PNG. URL זמני משתחרר בסגירה/החלפה.

גיבוי JSON בסיסי שומר את ספרי/עותקי/מחברי שלב 4, ההגדרות המותרות והתמונות. השחזור מציג ספירות, מאמת פורמט/גרסה, שדות, טיפוסים, מזהים, קשרים ו־hash תמונות לפני כתיבה. החלפה דורשת הורדת גיבוי קודם ואישור מפורש. לפני commit בודקים שהספרייה לא השתנתה מאז הגיבוי, והחלפה נעשית בעסקה אחת. אין merge בשלב זה; הפורמט המלא ומיזוג מגיעים בשלב 15. אם קיימות ישויות בשלבים מאוחרים שלא נכללות בפורמט הבסיסי, הגיבוי/השחזור נחסמים במפורש כדי לא לאבד אותן.

מחיקת ספר כוללת preview וגיבוי קודם; השאלה פתוחה/היסטוריה מונעות מחיקה ומציעות ארכוב עותקים. אין מחיקה אוטומטית או איחוד מחברים/ספרים.

## בדיקת סיום

- T09: ספר ללא שם/מחבר/ISBN; כמה מחברים; שלושה עותקים בשורה אחת; עריכה ושמירה אחרי reload; ארכוב; כשל כתיבה; revision ישן; שדות שנשללו אינם נשמרים.
- T10: תמונה אמיתית בדפדפן, הקטנה, MIME, hash, קובץ שאינו תמונה, ביטול ושחרור URL. אין בדיקת מצלמת iPhone פיזית.
- T19 בסיס: round trip של טקסט ותמונות; ספירות; דחיית קובץ עתידי/קשרים שבורים/תמונה פגומה/שדה סודי; כשל commit ושינוי מקביל משאירים את המקור ללא שינוי; אישור וביטול ב־preview.
- TypeScript, ESLint, בדיקות שירותים, בדיקות Chrome אמיתי ו־build. סקירת מחשב/360px ופוקוס/מקלדת בכרטיס. בדיקות דוגמה אינן אמת קטלוג/מודל ואינן מחליפות בדיקות הטלפון שנדחו.
