# Scan search reliability — App 0.25.0

Barcode image/camera recognition starts catalog search immediately. An exact single identifier result resolves and fills the edit draft; mismatched identifiers and multiple candidates require selection. No catalog response saves a book: Save remains explicit. Manual title search starts with title/author instead of a stale scanned identifier.

Dani Books is connected through the existing authenticated private catalog service. It accepts the observed 12-digit Danacode and publisher-book notation, follows only validated Dani product redirects as references, then reads the literal product Danacode, title, author and publisher from the public book page. It does not guess identifiers from SKU or extract a series from title. Unknown/multiple search pages currently produce no result. Covers are not imported from Dani in this release; a user image can still be added.

Live validation on 2026-10-08: code 067400002621 returned one reference and book 211686 with title מבצע תל אביב - שליחות חשאית 7, author דנה אלעזר הלוי, publisher ידיעות ספרים, and the exact code. Both authenticated endpoints returned HTTP 200 from Oracle. This proves that book, not universal catalog coverage.

The service retains its 0.25 CPU / 192 MiB memory / 64 process limits, one active upstream request, bounded HTML, 15-second timeout, 10-second provider cooldown, 200 upstream requests per provider per UTC day and bounded 24-hour cache. The SQLite provider constraint migrates atomically and retains existing budgets and holds. Only the library catalog container was replaced, with image 2 retained for rollback. Before installation: 35 GB free disk, around 10 GB available RAM, catalog about 33 MiB; new container health passed and used about 27 MiB immediately after startup.

The setting explains that the credential is the private catalog service token, shared by Dani and Goodreads, not a Goodreads API key. Simple Danacode search shows only the applicable Dani source and removes the misleading manual-search warning from Open Library, which is separate from the National Library of Israel.
