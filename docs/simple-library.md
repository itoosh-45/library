# App 0.19.0 — פישוט הספרייה

הבקשה העדכנית מחליפה את דרישת שימור כל הפיצ׳רים בממשק: פחות כלים ופחות מסכים. ספרים בתמונות, מדפים, חיפוש והוספה הם העיקר. ללא תמונה מוצג שם. כפתור הוספה פותח טופס קצר ישירות; סריקה וצילום הם עזר מתקפל. פרטים נוספים כוללים שפה, הוצאה, שנה ומזהים. בחירת תוצאה ממלאת כל פרט זמין וכריכה; סריקת מזהה תקין מפעילה חיפוש.

הוסרו מהניווט מסכי סטטיסטיקה, השאלות, סדרות, תגיות, ז׳אנרים, מחירים, עותקים, Excel וסריקת מדף מרובה. מימושים היסטוריים נשארו בקוד; אין שינוי סכימה או מחיקת נתונים. טופס עריכה משמר שדות מוסתרים, עותקים ושיוכים מרובים עד שינוי מפורש. גיבוי JSON מלא ו־Gemini אישי נשארו בהגדרות. המפתח נשמר בדפדפן הזה, מחוץ לגיבוי, עם מחיקה מפורשת; ניקוי נתוני הדפדפן יכול להסיר אותו.

## בדיקה וסקירה

184 בדיקות יחידה ו־5 בדיקות דפדפן של הממשק החדש עברו. בדיקת שימור מידע ישן זיהתה תקלה מכוונת באיפוס ז׳אנרים; הקוד הוחזר ובדיקה ממוקדת עברה. צילום טלפון ושולחן עבודה נבדקו; רוחב 320 אינו גולש. בדיקות UI ישנות המתייחסות למסכים שהוסרו אינן ברירת המחדל החדשה; קבציהן נשמרו כהיסטוריה, ואין טענה שהן עברו בגרסה זו.

סקירה בחמשת הצירים: תקינות — שירותי השמירה האטומיים ומידע ישן נשמרים; קריאות — ניווט של שלושה יעדים וטופס קצר; ארכיטקטורה — שימוש במסד ובשירותים הקיימים ללא שכבת נתונים חדשה; אבטחה — CSP, מפתח נפרד, ספקים מדומים בלבד וגיבוי מגן; ביצועים — מסך הראשי קורא ארבע טבלאות, ללא טעינת כלי Excel או סריקה מרובה. אין תלות חדשה.

Impeccable detect הופעל פעם אחת: תמונת blob מקבלת src באפקט ולכן סומנה סטטית; כריכות בפועל נבדקו בדפדפן. סימוני גבולות CSS מתייחסים גם לעיצוב הישן שנשמר. האתר לדוגמה לא נטען, ולכן הפישוט מבוסס על הדרישות ולא על השוואה מדויקת אליו. מכשיר טלפון אמיתי ודיוק ספקים חיים לא נבדקו. ללא קריאות Gemini אמיתיות או חיוב.

5 בדיקות PWA עברו: כריכה מקומית וכשל הורדה, CSP, זיהוי מדומה, גיבוי ושחזור ואופליין, ועדכון ששומר טיוטות וחוסם חלון נוסף. תוקנה מעטפת app-shell הדרושה לעדכון בטוח; תצוגת המעטפת הפשוטה היא block.
