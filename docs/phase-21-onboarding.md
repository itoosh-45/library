# שלב 21 — היכרות קצרה

הרחבה מאושרת אחרי מסירת שלב 20; WORK_PLAN.md נשאר ללא שינוי. App 0.17.0, schema 2, JSON 8 ו־Excel 1. אין תלויות, שירותים, סכימת מסד או קריאות ספק חדשות.

## השינוי

שלושה מסכים קצרים בתוך העמוד הקיים: יכולות הספרייה; שמירה מקומית וגיבוי; חיבור Gemini אישי ורשות. ההיכרות אינה חוסמת הוספה/ניווט. אפשר להתקדם, לחזור, לדלג, לסיים או לפתוח את הגדרות הזיהוי. בהגדרות יש כפתור לפתיחה מחדש. עברית/RTL, מיקוד בכותרת אחרי מעבר מפורש, הודעת מספר שלב וקו מיקוד נגיש; ללא אנימציה.

Heebo והצבעים הקיימים נשמרו: טורקיז #1F4D57, טקסט #213C42/#52666B, לבן, רקע #F7F9F9 וקורל #E0834A לסימון בלבד. מימוש bounded לפי brainstorming/frontend-design; ההנחיה המפורשת לעבודה אוטונומית בלי אישור עיצוב/חלופות גוברת על סבבי אישור הסקיל.

סמן דילוג זעיר ולא סודי נשמר ב־localStorage במפתח itoosh-library.welcome-dismissed.v1, נפרד מהספרייה ומגיבוי JSON. אין אחסון מפתח API בו. חסימת האחסון אינה מונעת שימוש: ההיכרות נסגרת למשך הביקור וייתכן שתופיע שוב ברענון. לא משתנים settings של הספרייה או checksum. אין העלאת תמונות/בקשות Gemini כחלק מההיכרות. חיבור אמת והסכמות נשארים בטופס הקיים; המפתח בזיכרון בלבד. Open Library ישיר; NLI/Google Books עדיין אינם פעילים בפרסום הציבורי.
