# ביקורת מחזור 4 — שלבים 7–8

שלב 7 המקומי הושלם; קוד `5cc42bac1dc48ed8f70bb9470b5da8e61b32f85c`, app 0.5.0/schema 2/backup 3. 77 בדיקות שירותים ו־18 בדיקות Chrome מבודדות עברו; build נבדק עם השאלה/החזרה/היסטוריה/שחזור וב־360px. [ראיות שלב 7](../phase-07-acceptance.md).

**שער מחזור 4 המלא פתוח.** שלב 8 בבנייה מקומית: חיפוש ובחירת שדות, מקור מוגן בגיבוי v4, כשלי API ומרוצים נבדקו. 92 בדיקות שירותים, 4 בדיקות כלי חיבור ו־21 בדיקות Chrome עברו; שלוש בדיקות שלב 8 הורצו שוב אחרי חיזוקי האימות. Open Library עבר ניסוי חי; NLI חזר בהמשך HTTP 200 עם מסנן material_type שנדחה ומבנה JSON-LD; שירות loopback ומיפוי ב־fixtures נבנו (99 בדיקות שירותים, 4 בדיקות Node ו־21 בדיקות Chrome). Google Books ללא מפתח, אימות מועמד NLI חי ומכסה ו־gateway ציבורי עדיין חסרים. לפי DECISIONS.md, המתנה לבדיקת המשתמש אינה עוצרת את העבודה העצמאית הבאה. [התקדמות שלב 8](../phase-08-progress.md). ניסויים חיים לכל ספק חובה, עשר תוצאות משתמש ובדיקות התשתית החלות עדיין פתוחים. אין לראות ב־fixtures או ב־CI ראיית ספק חי.

המשך בצ׳אט חדש באותו פרויקט לבקשת המשתמש, באותו מאגר קבוע. לפני שמירת metadataSources יש להרחיב את הגיבוי. אין שינוי n8n או פרסום מוצר. שירות gateway/דומיין חדש דורש הרשאה אם לא ניתנה, והקמה מבודדת. בדיקות היתכנות וטלפון שנדחו נשארות פתוחות ללא חסם חדש לבנייה מקומית שאושרה.
