# שלב 14 — ביצועים, App 0.12.0

המימוש והבדיקות המקומיות הושלמו. schema 2 ו־JSON v7 לא השתנו. אין שינוי בספקים חיים או ב־GitHub Pages. נעילת התשלומים חלה בכל העבודה. המשתמש ביקש לסיים שלב זה ולעצור; שלב 15 לא התחיל. שער 7 המלא עדיין אינו PASS: מכשיר יעד ובדיקות חיות חסרים, ו־5,000 ספרים חורגים בחלק מהתקציבים.

## שינוי ותנאי המדידה

כריכות נטענות מ־IndexedDB רק סמוך למסך באמצעות IntersectionObserver משותף, ומנויי התמונות וכתובות Blob משתחררים ביציאה. רשימות ספרים רציפות מחליפות ul לכל ספר; קבוצות, מסננים ומיון משתמשים בתוצאות שמורות כשהקלט לא השתנה. בספרייה מ־1,000 ספרים, כאשר יש לכל היותר מקטע רגיל אחד, שורותיו נשמרות עם hidden בין חיפושים. שורות מוסתרות אינן בתוצאות, במיקוד או בעץ הנגישות. בכמה מקטעים נשמר הרינדור הרגיל וסדר הקבוצות. פס האותיות משתמש בחיפוש בינארי וב־animation frame במקום קריאת גאומטריה של כל השורות בכל אירוע גלילה. מיקוד אחרי עריכה שורד החלפת שורה ופעולת משתמש מבטלת שחזור מאוחר. הודעת quota מזהה גם שגיאת Dexie עטופה. אין ספרייה חדשה, worker או וירטואליזציה; ניסוי content-visibility הוסר אחרי שנמדדה עלות DOM גבוהה.

הנתונים סינתטיים ודטרמיניסטיים בלבד: 1,000 ספרים/1,600 עותקים/2,000 השאלות היסטוריות, או 5,000 ספרים/8,000 עותקים/10,000 השאלות היסטוריות. בשניהם 50 השאלות פתוחות, 100 מחברים ואנשים, 20 תגיות, 150 מדפים בשרשרת וסדרה בת 200 ספרים. לכל ספר JPEG תקין 240×320, 7,294 bytes; זו אותה תמונה סינתטית עם IDs שונים, לא מדגם תמונות אמיתי או הוכחת ממוצע 50KB בנתוני משתמש. fixtures נשארים JSON v7 של App 0.11.0 כדי לבדוק תאימות. השחזור דרך preview וגיבוי מגן בפרופיל בדיקה ובאוריג׳ין 4335 בלבד.

Windows desktop Chrome 154.0.8037.97, viewport 390×844, DPR 1, localhost ללא האטת רשת יזומה. אין טענת מדידת iPhone. בכל ריצה חמש פתיחות חמות, 30 חיפושים צרים ו־30 רחבים, 30 עריכות ו־30 השאלות והחזרות. p95 הוא nearest-rank. מדידת דפדפן: אירוע input/click → שינוי תוצאה ב־DOM אחרי commit → שני frames. זמני automation כוללים גם פעולה והמתנות Playwright, ומדווחים בנפרד.

חמש פתיחות דף אחרי unregister של worker, מחיקת cache של אוריג׳ין הבדיקה וניקוי HTTP cache: p95 663ms ב־1,000 ו־1,501ms ב־5,000. אותו תהליך Chrome ואותו IndexedDB; זו אינה פתיחה אחרי restart אמיתי של דפדפן/מערכת או iPhone. דוחות מקומיים: private/phase14-benchmark/release-012-1000.json ו־scoped-dialog-5000-5000.json. הם מוחרגים מ־Git; דוח זה מכיל aggregates בלבד.

בשתי הריצות ארבע תמונות בתחילת הרשימה ו־15 לאחר גלילה לקצה, מול 1,000/5,000 ספרים; הכריכה האחרונה נטענה. 19 כתובות Blob נוצרו, ארבע שוחררו ו־15 נשארו פעילות אחרי הגלילה. כשל הביניים שבו polling כללי ל־img נראה ככריכה חסרה לא שוחזר בבדיקת complete/naturalWidth ובבוררים ממוקדים; הוא אינו מסומן כתקלה פתוחה. אין globals של אבחון בקוד המוצר.

## בדיקות וביקורת

PASS מקומי בגרסת הסיום: npm run check — טיפוסים, lint, 143 Vitest, ארבע Node, build אפליקציה ושער; 39 בדיקות דפדפן; שש production PWA; שתי production performance (1,000 ו־quota). ריצת stress 5,000 עברה מוקדם יותר כמפורט לעיל. בדיקות החיפוש/מיון/סדרות, הגלילה והמיקוד, השאלות ושני חלונות, scanner וביטול הרשאת מצלמה מאוחרת, תמונות/זיהוי/ביטול, סקירת מדף, אופליין ועדכון בטוח חזרו ועברו. צילומי desktop/360px ונתוני מדידה נשמרים תחת test-results המוחרג.

Quota: native IDBObjectStore.add זורק DOMException QuotaExceededError בכתיבה השלישית של תמונה במהלך שחזור. כל טבלאות הספרייה הקודמת זהות לפני/אחרי וגם אחרי רענון. זו בדיקת rollback תחת כשל מוזרק, לא מילוי אמיתי של דיסק או מכסת טלפון. ניסוי רגישות הפיך הסיר את הגנת source של observer: הבדיקה נכשלה על callback ישן לאלמנט שנרשם מחדש; הקוד שוחזר והבדיקה עברה.

ביקורת בחמישה צירים: נכונות — empty search, קבוצות/סדרות ומיקוד אחרי העברת ספר, rollback ועקביות בין חלונות מוכחים. קריאות — helper קטן לניקוי observer ו־focus מוגבל ל־2s; אבחון זמני הוסר. ארכיטקטורה — DB/עסקאות וגרסאות פורמט נשמרים, config נפרד ל־production benchmark, ללא dependency או מנגנון cache נתונים נוסף. אבטחה — נתונים סינתטיים בלבד, logs ללא מפתחות, אין חיוב או גישה חיה חדשה, React מציג טקסט ולא HTML חיצוני. ביצועים — פחות מנויי תמונות וקריאות layout, תקציבי 1,000 מוכחים במחשב; רשימה גדולה נשארת DOM מלא ו־5,000 מוגבל כמפורט. אין ממצא מקומי פתוח החוסם מיזוג קוד; ראיות שער 7 נשארות חסרות.
