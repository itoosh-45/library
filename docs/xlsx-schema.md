# Excel template 3 — schema 2

Excel הוא פורמט טבלאי לעריכה ולהעברת נתונים. JSON הוא גיבוי השחזור המלא, עם תמונות וטיוטות צילום מדף; גרסה 11 שומרת גם תאריך פרסום וסוג כריכה. Excel template 3 מוסיף את השדות ו־hasPublicationDate/hasBinding כדי לשמר את ההבדל בין שדה חסר לשדה ריק. template 1–2 ממשיכים להיות נתמכים. קובצי Excel אינם מוצפנים וכוללים אנשים, השאלות ורשמים אישיים. מפתחות, מטמון ותשובות ספק גולמיות אינם נכללים.

## גיליונות הקובץ המלא

| גיליון | תוכן וקשרים |
|---|---|
| Manifest | format=my-library-xlsx, templateVersion=3, dbSchemaVersion=2, libraryId, exportedAt, הוראות וכל עמודה/סוג/אפשרות עריכה |
| Books | כל שדות הספר scalar, ללא מערכי שיוך; titleSortKey מחושב מחדש בייבוא |
| Copies | bookId; מחיר ביחידות קטנות של currency, ארכוב, תאריכים והערות |
| Authors | שמות ומזהים; normalizedName מחושב מחדש |
| BookAuthors | bookId/authorId/position, סדר מחברים החל מ־0 |
| Shelves | parentId/imageId, שם, סדר ותאריכים |
| BookShelves | id/bookId/shelfId; שיוך ייחודי |
| Series | אוסף וסימון collapsed בוליאני |
| Genres / Tags | שמות ייחודיים בתוך סוג אוסף |
| BookGenres / BookTags | bookId/genreId או tagId, position ברצף החל מ־0 |
| People | אנשים ומצב ארכוב, ללא איחוד שמות זהים |
| Loans | copyId/personId וכל ההיסטוריה, כולל השאלות שהוחזרו |
| MetadataSources | פרטי מקור; fieldValues/selectedFields/userOverriddenFields/recognition כ־JSON מובנה בתאי טקסט |
| Settings | רשימת ההגדרות המותרות של JSON בלבד |
| ImageRefs | id/sha256/sourceUrl בלבד, ללא Blob/base64 |

העמודות המדויקות ב־src/data/xlsxSchema.ts ומופיעות גם ב־Manifest. הכותרת בשורה 1, הנתונים מתחילים בשורה 2. ריק הוא null; אין להסיק אפסים שהוסרו מתא מספרי. מזהים, ISBN/דאנאקוד ותאריכי ISO הם string; מספרים ובוליאנים כתובים לפי הסוג. טקסט שמתחיל `=`, `+`, `-`, `@` נשמר כתא string, ללא formula. אין macro או external link ביצוא.

קשרי מערך נמצאים בגיליונות נפרדים עם position לשימור סדר. שינוי שם/כותרת מחשב מחדש מפתח חיפוש; שינוי שדה שנבחר מקטלוג נרשם ב־userOverriddenFields, תוך שימור מקורו. ספר ללא Copies מקבל עותק ראשון עם מזהה יציב. קובץ מלא חייב לכלול בדיוק את כל 17 הגיליונות והעמודות הנתמכות; worksheet לא מוכר וגרסה עתידית נדחים.

## תמונות וטיוטות

אין הורדת תמונה מהרשת בייבוא. קובץ תמונה קיים ביעד משמש רק כשה־id וה־SHA-256 תואמים להפניה. אם חסר, קשר התמונה בנתונים המיובאים מוסר, מספר הקשרים החסרים מוצג ונדרש אישור מגבלת התמונות. ImageRefs אינו הבטחת שחזור של תמונות.

טיוטות צילום מדף אינן יוצאות ל־Excel. תוצאות שכבר נשמרו ומקורותיהן כן יוצאים. מיזוג שומר את טיוטות/נתוני היעד; החלפה מסירה טיוטות ותמונות שאינן כלולות בנתונים המיובאים, עם אזהרה ואישור וגיבוי JSON מגן. אין לייבא קובצי ניסוי לספרייה אישית כדי לבדוק זאת.

## Books פשוט

גיליון יחיד ללא Manifest, עם שורת כותרת. שמות עברית/אנגלית מוצעים אוטומטית ואפשר לשנות או להתעלם מכל עמודה לפני preview. אין מיפוי שתי עמודות לאותו שדה. המיפוי כולל שם, כותרת משנה, מחברים, ISBN, דאנאקוד, הוצאה, שנה, מהדורה, כרך, שפה, עמודים, רשמים, מצב קריאה, כמות עותקים, מחיר/מטבע/הערות עותק ותאריך הוספה.

מחברים מופרדים ב־`;`. כמות ריקה משמעה עותק אחד, 1–100 לשורה ועד 20,000 בקובץ. מחיר עד מיליון ביחידות המטבע, עד שתי ספרות אחרי הנקודה; מטבע שלוש אותיות גדולות, ברירת מחדל ILS רק כשיש מחיר. תאריך טקסט YYYY-MM-DD או ISO UTC מלא; אם חסר נרשם מועד הייבוא הראשון. מידע ספר שאין לו מקור נשאר null. ISBN/דאנאקוד מספריים נדחים עם בקשה לתא טקסט.

מיזוג בלבד לקובץ פשוט. המזהים נגזרים מטביעת בתים/גיליון/שורה; אותו קובץ מיובא שוב ללא תוספות. קובץ ששונה הוא מקור חדש ועובר סקירת כפילויות מחדש. שינוי מקומי נשמר או נבחר במפורש בסתירה; מהדורות אינן מתאחדות לפי שם/ISBN.

## קלט לא מהימן וגבולות

לפני SheetJS נבדק ZIP: עד 10MiB לקובץ, 512 entries, 16MiB ל־entry ו־64MiB מנופחים במצטבר; local/central headers ו־data descriptors כשיש streaming, אי־חפיפה, CRC, ונפח בפועל בעת פענוח בזרם מוגבל. ZIP64 (גם ב־extra fields), שמות חלופיים, הצפנה, binary/macro/external parts, DTD/entities וקישורים חיצוניים נדחים. XML UTF-8 בלבד. הגדרת MIME ברירת מחדל לא פעילה אינה תוכן macro; חלק פעיל או workbook מסוג macro נדחים.

עד 20,000 שורות נתונים בגיליון, 64 עמודות ו־500,000 תאים בחוברת. בודקים תא מסוג formula גם אם יש cached value; אין שימוש בתוצאה מחושבת. תאים מסוג error וקישור פעיל נדחים. תא JSON מובנה עדיין כפוף לאימות המקור/סכמה ולא מאפשר שדות חופשיים. יצוא שעובר את הגבולות נחסם ומציע JSON. פענוח דחיסה בטוח דורש DecompressionStream/deflate-raw (Safari 16.4 ומעלה לפי נתוני התאימות של MDN); מכשיר פיזי עדיין דורש בדיקה.

קלט ומיזוג משולב עוברים את validator של JSON; קשר חסר, מעגל מדפים או היסטוריה סותרת אינם נכתבים. התצוגה המקדימה קוראת בלבד. commit דורש גיבוי JSON, סקירה ואישור; משתמש במסלולי restoreSnapshot/mergeSnapshot האטומיים שנבדקו, כולל guard מול שינוי במקביל. שגיאות תא מציגות גיליון/שורה/עמודה; שגיאה ברמת חוברת/קשרים מציינת מיקום כללי במקום להמציא שורה.

## דוגמאות ומקורות

public/templates/full-example.xlsx הוא מאגר סינתטי עם קשרים, אנשים, השאלה פתוחה/סגורה ומקור מידע; public/templates/Books-template.xlsx הוא תבנית פשוטה עם שורת דוגמה שמוחקים לפני ייבוא. הם נוצרים דרך אותו מנגנון המוצר ונבדקים גם ב־CI. אפשר להפיק מחדש במפורש באמצעות GENERATE_XLSX_FIXTURES=1 ובדיקת published full example; CI רגיל אינו כותב אותם.
