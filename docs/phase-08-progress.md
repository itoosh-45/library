# שלב 8 — התקדמות מקומית, 2.10.2026

**השלב ושער מחזור 4 עדיין פתוחים.** App 0.6.0 / schema 2 / backup 4. אין פרסום מוצר או שינוי GitHub Pages.

נבנו חיפוש מפורש, תוצאות חלקיות, בחירת שדות מועמד ועריכה לפני שמירה. בחירה אינה שומרת ספר אוטומטית. יצירה אינה מספקת ISBN או שנת מהדורה; כפילות ISBN שומרת את מסלול בחירת העותק. מקור, שדות שנבחרו ושדות שנערכו ידנית נשמרים יחד עם הספר בעסקה אחת, נכללים בגיבוי v4 ומשוחזרים. גיבויי v1–v3 מקבלים רשימת מקורות ריקה עם אזהרה; מטמון אינו נכלל בגיבוי.

## ראיות מקומיות

- `npm run check`: TypeScript, ESLint, 92 בדיקות Vitest, 4 בדיקות Node לכלי החיבור המקומי ו־build עברו.
- אחרי חיזוקי האימות וההמתנה ל־429 עברו כל 21 בדיקות Chrome מבודדות, כולל שלוש בדיקות שלב 8: בחירה/עריכה/שחזור, כפילות וכשל ספק/טקסט לא מהימן/360px.
- ניסוי רגישות: שינוי מכוון בזיהוי Work הכשיל חמש בדיקות; המקור שוחזר והבדיקות עברו. אין שינוי מכוון שנשאר בקוד.
- ניסוי Open Library אמיתי ב־ISBN ציבורי 9780140328721 החזיר מועמד ומהדורה עם מחבר, ISBN, הוצאה, שפה ועמודים. תאריך טקסט עמום לא הומר לשנה. לא הוחלו שדות ולא נשמר ספר. ראיות מסוננות וצילומים תחת `private/phase08-preview/`, מחוץ ל־Git.
- תצוגת ה־build ב־4331 עברה שחזור גיבוי סינתטי v4, שמירת מקור ועריכה ידנית אחרי רענון וייצוא חוזר. נבדקו 1440px ו־360px ללא גלישה אופקית, שגיאות JavaScript או בקשות חיצוניות. הצילום הצר נבדק חזותית.

## ביקורת והעלאה

המשתמש ביקש להעלות את המצב הקיים ל־main למרות החיבורים שטרם הושלמו. זהו מיזוג התקדמות, ולא אישור השלמת השלב. נבדקו נכונות, קריאות, גבולות המודולים, אבטחה ומגבלות ביצועים: אין תלות חדשה; פלטי ספקים עוברים אימות; השמירה והשחזור אטומיים; בקשות ומועמדים מוגבלים; תגובות מוגבלות ל־2MB לפני אגירה מלאה. חיפוש ישן וביטול אינם מחילים תוצאות על ספר. גם לקוח ה־gateway שומר Retry-After לאחר 429 בין פתיחות הכרטיס. מידע אישי ומפתחות לא נכללים בקוד או בראיות שב־Git.

## התאמה לכללי הספרייה הלאומית

כלי הבדיקה המקומי `gateway/local-nli-check.mjs` שולח בקשה אחת ל־`https://api.nli.org.il/openlibrary/search`, עם המפתח שהוזן ועם `query=title,exact,Jerusalem`, `material_type=books`, `output_format=json`, `items_per_page=2`, `result_page=1`. הפרמטרים נבדקו מול [ממשק החיפוש](https://www.nli.org.il/he/research-and-teach/open-library/search-api) ו־[הוראות השימוש](https://www.nli.org.il/en/research-and-teach/open-library/search-api/user-help).

המשתמש הזין מפתח פעם אחת במסך מקומי. התקבל HTTP 500; אין די בכך לקבוע אם הסיבה במפתח, בשירות או בבקשה. כותרת `Errors` לא נאספה בבדיקה הראשונה. נוספה קריאה של קודים מספריים בלבד מהכותרת לבדיקה עתידית; הודעות גולמיות ומפתחות אינם נשמרים. אין ניסיון חוזר אוטומטי ואין מפתח שמור לשימוש חוזר.

זהו כלי אבחון ב־127.0.0.1:4332, ולא שירות הקטלוג של המוצר. להפעלה: `node gateway/local-nli-check.mjs`. נדרשת הזנת מפתח חדשה לבדיקת חיבור נוספת. הקישור הידני לדאנאקוד משתמש במסלול האתר שנצפה בהיתכנות, שומר אפסים מובילים ואינו מוכיח חיפוש API אוטומטי.

## מה נותר

ב־2.10 המשתמש בדק את תצוגת הביניים ב־4331 והשיב ״הממשק עובד כפי שציפיתי״ לשאלה על בחירת שדות ללא שמירה אוטומטית. זו ראיית קבלת ממשק, ולא ניסוי של שלושת הספקים. בדיקות GitHub עברו על `dc7d359d5af454b1e5d49a46e385bf170ead4ff7`: https://github.com/itoosh-45/library/actions/runs/37036510593 .

נרשמו בהמשך שתי תגובות NLI עם HTTP 200. האבחון האחרון זיהה `material_type` כפרמטר שנדחה בקוד 1010. המסנן הראשון הסתיר שמות שדות URI; תוקן ונבדק. האבחון המתוקן הציג JSON-LD: מערך שתי רשומות, עם שדות title/creator/publisher/date/isbn/type/recordid/identifier/language המורכבים ממערכי `@value`. אין גוף ספק או מפתח שנשמרו; המבנה המסונן נשמר תחת private בלבד.

נבנו `gateway/catalog-server.ts` ו־`gateway/nli.ts`: שירות loopback, מגבלות גוף/זמן/מקבילות/קצב/מכסה מפורשת, סודות שרת בלבד, פלט מועמד מאומת, יעדים סגורים ושגיאות בטוחות. Google Books משתמש במיפוי המשותף; NLI אינו שולח material_type שלא התקבל, דוחה Errors ואינו מפעיל חיפוש ISBN/דאנאקוד שלא אומת. חומר שאינו book/books/ספר מפורש מוצג כרמז כללי ללא ISBN/שנה. NLI כבוי כברירת מחדל עד אימות mapping חי ומכסה. השירות המקומי הבנוי עבר health=200; אין IndexedDB/Dexie או סוד ב־bundle שלו. [הפעלה וגבולות](../gateway/README.md).

אחרי ההמשך: `npm run check` עבר עם 99 בדיקות Vitest ו־4 בדיקות Node, ושני builds. ניסוי מעקף Origin מכוון הכשיל בדיקת אבטחה; המקור שוחזר ושבע בדיקות השירות/מיפוי עברו שוב. אין שינוי מכוון שנשאר. כל 21 בדיקות הדפדפן המצטברות עברו שוב לפני המיזוג (1.0 דקות).

נותרו אימות מועמד NLI מלא וסוגים/תפקידים מול רשומה אמיתית, מכסה והפעלה; מפתח וניסוי חי של Google Books; פריסה ובידוד gateway ציבורי, עשר תוצאות משתמש וראיות מכשיר לשער מחזור 4. לפי התנאים החדשים ב־DECISIONS.md, חוסר מענה או מפתח אינו עוצר את העבודה העצמאית במחזורים הבאים; השער החסר אינו מסומן PASS.
