# שלב 7 — אנשים, השאלות והיסטוריה

המשך התוכנית המאושרת, במאגר הקבוע בלבד. שלב 8, חיבורי קטלוג ופרסום מוצר אינם חלק מהשינוי.

1. גיבוי בסיסי v3 לפני שמירת אנשים והשאלות. שמירת שם בלבד לאדם, מצב ארכוב והיסטוריית השאלות לעותק. אימות whitelist, קשרי אדם/עותק, openFlag הנגזר מ־returnedAt, השאלה פתוחה אחת ללא חפיפות, תאריכים וספירות. שחזור v1/v2 נתמך ומחליף אנשים/השאלות ברשימות ריקות, עם אזהרה בתצוגה המקדימה. fingerprint, גיבוי מגן, אישור ושחזור אטומי נשמרים. metadataSources ממשיך לחסום גיבוי במפורש.
2. שירותי השאלה והחזרה בעסקאות: עותק פעיל ואדם פעיל, חסימת השאלה כפולה/מרוץ שני חלונות, תאריך השאלה היום או בעבר ותאריך צפוי רשות שאינו לפני ההשאלה. החזרה אינה מוחקת היסטוריה ואינה יכולה להירשם פעמיים או לפני ההשאלה. date-only נשמר YYYY-MM-DD; מועדי האירועים UTC. תאריך אירוע היסטורי נרשם בצהריים ביום המקומי שנבחר; היום נרשם בזמן הפעולה.
3. אנשים עם שם בלבד, יצירה/עריכה וארכוב. אדם בעל אותו שם אינו מתאחד אוטומטית: נדרש אישור יצירת אדם נפרד; הבחירה מציגה הבחנה לפי מספר אדם כשיש כפילות. שינוי ישן נחסם; ארכוב אדם עם השאלה פתוחה נחסם. אין מחיקה של אדם או היסטוריה.
4. מתוך כרטיס ספר בוחרים עותק זמין ואדם קיים או חדש. השאלה/החזרה חסומות כשהספר או העותק מכילים שינויים שלא נשמרו. טאב השאלות מקובץ לפי אדם, עם היסטוריה ותאריך צפוי; באיחור בתוך UI בלבד. רשימת הספרים מציגה מושאל ומספר עותקים זמינים מיד לאחר פעולה. אין הודעות, תזכורות או שירות חיצוני.
5. T14: שלושה עותקים ושני אנשים, כפילות שמות ללא איחוד, השאלה כפולה, מרוץ חלונות, החזרה כפולה, תאריכים, ארכוב והיסטוריה, עדכון תג וזמינות, גיבוי שימושי בכל פעולה. T19: v3 round trip, v1/v2, שדות וקשרים שגויים, חפיפות, rollback ושינוי מקביל. כל רגרסיות 3–6, npm run check ו־Chrome מבודד, build במחשב ו־360px. בדיקות טלפון אמיתי נשארות פתוחות; אין סימון שער 3/4 מלא PASS.
