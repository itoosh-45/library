# שלב 9 — סורק ומזהים, גרסה 0.7.0

נבנתה זרימה מתוך עורך הספר: מצלמה אחורית לפי זמינות, חיתוך מרכזי שניתן לביטול, פנס ומיקוד רק כשהמצלמה מדווחת על תמיכה; תמונת ברקוד מקומית והקלדה הן חלופות. אין שליחת תמונות או פריימים לשרת ואין שמירה אוטומטית של ספר.

BarcodeDetector נבחר רק אם EAN-13 נתמך. בהיעדרו או בכשל runtime, ZXing נטען מקומית ועצל; הפענוח מנסה גם סיבוב של 90 מעלות. קוד שנקרא מפסיק את המצלמה וממתין לבדיקה מפורשת. ISBN עובר checksum ותחילית ספר; EAN כללי אינו הופך ל־ISBN או דאנאקוד. המשתמש בוחר דאנאקוד במפורש, עם אפסים מובילים. המזהה המאושר עובר לטיוטה ולחיפוש הקטלוג; בחירת שדות ושמירת הספר נשארות מפורשות.

סגירה, ביטול, החלפת מצב או הקלדה מבטלים תגובות ישנות. stream שמגיע אחרי ביטול נעצר מיד. זיהוי, ניתוק track, כשל setup ויציאה משחררים את tracks. תיקון ב־Sheet מונע מאירוע Escape של חלון פנימי לסגור גם את עורך הספר.

## ראיות מקומיות

- `npm run check`: typecheck, lint, 108 בדיקות Vitest, 4 בדיקות Node ושתי בניות עברו.
- `npm run test:browser`: כל 26 הבדיקות עברו. חמש החדשות מאמתות תיקון מזהה ודאנאקוד, בחירת מועמד ושמירה מאושרת עם רענון, PNG סינתטי EAN-13 בשני כיוונים עם native חסר או נכשל, תשובת permission מאוחרת אחרי Escape והרשאה נדחית.
- פענוח התמונה עבר ללא בקשות חיצוניות וללא שגיאות pageerror. צילום מסך סינתטי ב־360px נבדק; אין גלילה אופקית. הדיאלוג ניתן לגלילה אנכית.
- ניסוי ביקורת: הפיכת תנאי הביטול שאחרי getUserMedia הכשילה את בדיקות הסורק. הקוד שוחזר לפני בדיקות ההצלחה; הפלט מקומי ומוחרג ב־`private/phase09-review/cancellation-mutation.txt`.
- בניית production: main כ־424.94KB (gzip 130.30KB), חלון סריקה נפרד כ־8.53KB (gzip 3.47KB), ותלות ZXing נפרדת כ־480.95KB בשני chunks (gzip כ־127.15KB), נטענת רק בעת צורך במפענח החלופי. אין CDN. גרסאות ורישיונות ב־`docs/package-selection.json`.

## ביקורת איכות לפני שילוב

נכונות: בדיקות checksum, ביטול, כפילות סריקות באמצעות עצירה אחרי קריאה, fallback ושמירה מפורשת; כשל Escape שנמצא תוקן ונבדק. קריאות: שירות המצלמה והפענוח מופרדים מה־UI ומזרימת שמירת הספר. ארכיטקטורה: שימוש ב־parseISBN הקיים ובמסלול הקטלוג המקורי, ללא entity נוסף או שינוי סכימה. אבטחה: file MIME וגודל עד 20MB, decoder מקומי, ביטול URL לאחר פענוח, ללא מפתחות או לוג של נתוני משתמש. ביצועים: פריים אחד בכל פעם, השהיה 350ms, רוחב עד 1280 במצלמה/צלע עד 2048 בתמונה, decoder עצל ותמונה שאינה נשמרת ב־DB.

## חסר וטרם אומת

20 קודים פיזיים, תאורה חלשה, camera indicator ודגם הטלפון שנבחר טרם נבדקו. שאלת המשתמש נשלחה ללא עצירת הבנייה. בדיקות מחשב וסינתטיות אינן PASS עבור iPhone או יעד 90% בקודים אמיתיים. אימות ספקי NLI/Google החי נותר פתוח מהשלב הקודם; התוצאה אינה ספר מומצא כאשר חיפוש מזהה אינו זמין. שער 5 המלא תלוי גם בשלב 10 ובראיות המכשיר והזיהוי שלו. המשך העבודה העצמאית מאושר ב־DECISIONS.md, בכפוף לנעילת התשלומים.
