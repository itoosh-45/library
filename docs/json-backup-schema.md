# סכמת גיבוי JSON 8

App 0.13.0, DB schema 2. יצוא רגיל וגיבוי מגן משתמשים בפורמט 8. אין שינוי בסכמת IndexedDB. האפליקציה קוראת גם גיבויים 1–7; גרסאות אפליקציה ישנות שאינן מכירות 8 אינן קוראות קובץ זה. גרסה עתידית או שדות לא מוכרים נדחים לפני כתיבה. הקובץ אינו מוצפן ואינו מוכיח מי יצר אותו.

## מעטפת

| שדה | ערך/משמעות |
|---|---|
| format | my-library-backup |
| formatVersion | 8 |
| dbSchemaVersion | 2 |
| appVersion | מחרוזת גרסת האפליקציה המייצאת |
| libraryId | UUID, תואם להגדרת libraryId |
| exportedAt | תאריך ISO של הפקת הקובץ |
| tables | אובייקט של מערכי הטבלאות להלן, ללא images |
| images | מערך תמונות עם base64 במקום Blob |
| manifestCounts | מספר רשומות לכל אחת מטבלאות Core כולל images |
| checksums | אובייקט עם payload בלבד: SHA-256 של UTF-8 JSON.stringify של נתוני tables ואחריהם images |

ל־checksum יש רגישות לסדר השדות; אין לערוך JSON ידנית בלי יצוא מחדש. הוא מאתר שינוי/שיבוש ואינו חתימה או הוכחת אמינות. בנוסף כל תמונה נבדקת מול SHA-256 של הבתים המפוענחים, byteLength, ממדים וסוג הקובץ. כאשר זמין createImageBitmap נבדק פענוח בדפדפן.

## טבלאות וקשרים

הטיפוסים המדויקים מוגדרים ב־src/data/models.ts; רשימת השדות והאימות ב־src/data/backup.ts, metadata.ts ו־shelfDraft.ts. אין שדות חופשיים מעבר לטיפוסים.

| טבלה | קשרים/תוכן |
|---|---|
| books | UUID, כל שדות הספר, authorIds/genreIds/tagIds, seriesId, primaryImageId, revision |
| copies | UUID, bookId, מחיר ביחידות קטנות, מטבע, ארכוב ותאריכים |
| authors | שמות מחברים, ללא איחוד לפי שם |
| shelves | parentId ללא מעגל, imageId, סדר ותאריכים |
| bookShelves | UUID, bookId, shelfId; שיוך ייחודי |
| genres / tags | UUID, שם ושם מנורמל ייחודי בתוך סוג האוסף |
| series | כמו אוסף, כולל collapsed |
| people | שמות וארכוב; שמות זהים מותרים עם מזהים שונים |
| loans | copyId/personId, תאריכי השאלה/החזרה, openFlag; ללא חפיפה לעותק |
| metadataSources | bookId, מקור, שדות שנבחרו/נערכו, ראיות זיהוי תקינות שנשמרו |
| recognitionDrafts | טיוטות מדף מובנות, תמונות, פריטים, סקירה, החלטה ומזהי רשומות שנשמרו |
| settings | libraryId, libraryName, displayMode, preferredModel, lastBackupAt, lastBackupCheckedAt בלבד |
| images (בנפרד) | id, base64, mimeType, width, height, byteLength, sha256, sourceUrl, createdAt |

lastBackupAt מציין את ההפקה האחרונה שנרשמה לאחר בקשת הורדה. lastBackupCheckedAt מציין את תאריך ההפקה של הקובץ שהמשתמש אישר שנשמר ונבדק, ולא מדידת גישה ל־Files או זמן אישור עצמאי. שני תאריכים אלה מוחרגים מטביעת הגיבוי המגן; נתוני הספרייה האחרים אינם מוחרגים. החלפה משחזרת הגדרות הקובץ; מיזוג שומר את הגדרות היעד. מטמון, מפתחות ותשובות ספק גולמיות אינם נכללים.

## גבולות ובטיחות

קובץ עד 150MiB ב־UTF-8, לכל מערך עד 20,000 רשומות. זו תקרת קלט ולא הבטחת ביצועים במכשיר. יצוא מוערך לפני המרת תמונות ל־base64, ומאומת שוב באותו validator. Snapshot נקרא בעסקת קריאה; קידוד התמונות נעשה מחוץ לה. השחזור/המיזוג מאמתים את כל הנתונים יחד לפני transaction כתיבה אחת. שינוי מאז הגיבוי המגן חוסם כתיבה; שגיאה/abort מחזירים את המצב הקודם.

מיזוג מאותה libraryId משתמש במזהים הקיימים ובבחירה מפורשת בסתירות. מספרייה אחרת המזהים נגזרים מיעד/מקור/טבלה/UUID, וכל הקשרים ממופים, לרבות מזהי פריטי סקירה ומקור Gemini הנגזר. שמות מתנגשים אינם מאחדים ישויות. קובץ עתידי, checksum פגום, קשר חסר, מעגל מדפים או היסטוריה סותרת אינם עוברים אימות. גיבויים ישנים עלולים להכיל פחות סוגי ישויות; התצוגה מזהירה לפני החלפה.

דוח הניסוי הגדול והפערים למכשיר: phase-15-progress.md. אין לפתוח קובצי בדיקה סינתטיים על הספרייה האישית לצורך ניסוי.
